# 상어 SOS 안드로이드 아이콘 v2

2026-10-02. 기존 상어와 주황색 구명튜브를 유지하고 사각 프레임을 제거한 아이콘 제작 결과다. Built-in ImageGen으로 그림과 투명 전경, 바다 배경을 제작했다. 처음에는 별도 납품본이었고, 2026-10-02 versionCode 4(1.3)부터 앱 아이콘 원본으로 적용했다.

| 파일 | 용도 |
|---|---|
| `icon-1024.png` | 배경과 전경을 합성한 불투명 1024×1024 완성 아이콘 |
| `foreground-1024.png` | 108dp 좌표계의 투명 전경, 1024×1024 |
| `background-1024.png` | 같은 좌표계의 불투명 바다 배경, 1024×1024 |
| `preview-circle.png` | 원형 표시 미리보기, 바깥 영역 투명 |
| `preview-rounded-square.png` | 둥근 사각형 표시 미리보기, 바깥 영역 투명 |
| `comparison.png` | 기존 아이콘과 신규 모양, 48/64/96px 비교 |
| `source/*.png` | ImageGen의 1254×1254 원본 3개 |
| `PROMPTS.txt` | 실제 사용한 생성 프롬프트 3개 |
| `export.ps1` | 규격 정리와 미리보기 재생성 스크립트 |
| `validation.txt` | 전경의 안전 영역 검사 결과 |

전경과 배경을 정렬하고, 전경의 알파 16 이상 픽셀이 중앙 지름 66dp 안전 원 안에 들어가도록 비율을 유지해 배치했다. 아트 원본은 보존했다. 완성형 아이콘과 미리보기는 두 레이어 중앙 72dp 영역을 합성하므로 실제 레이어와 내용이 일치한다. 이는 일반적인 런처 모양의 정적 미리보기이며 기기별 애니메이션이나 실물 기기 검증 결과는 아니다.

전경은 이미 적응형 아이콘 여백을 포함한다. 향후 Android 적용 시 추가로 축소하지 말고 기존 `tools/icons.js`의 완성형 그림 축소 방식과 `<inset>` 중복 적용을 확인해야 한다. 배경은 전체 레이어를 빈틈없이 채워야 한다. 적용: `tools/icons.js`가 `icon-1024.png`로 PWA·Play·스플래시 아이콘을 만들고, `@capacitor/assets`가 두 레이어를 `<inset 16.7%>`로 감싸므로 전경·배경은 축소 없이 가운데 72dp만 잘라 원본으로 넘긴다. 생성된 적응형 아이콘의 합성 결과는 `icon-1024.png`와 같다.

재생성: 이 폴더의 `export.ps1`을 Windows PowerShell에서 실행한다. 일반 RGB/알파 및 1024px 출력 규격을 사용하며 추가 패키지가 필요 없다.
