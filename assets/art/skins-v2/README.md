## 원본과 납품 파일

- 제작 도구: built-in ImageGen. 외부 다운로드 아트나 새 유료 라이브러리를 추가하지 않았다.
- 기준 이미지: `../source/shark-portrait.png`, `../source/shark-swim.png`. 얼굴·방향·신체 비율과 각 카메라를 참조했다.
- 전체 제작 명세: [PROMPTS.md](PROMPTS.md). 테마별 1회, 총 8회 생성.
- `source/*.png`: 투명 배경의 생성 원본 8개. 왼쪽 선택 화면용, 오른쪽 위에서 내려다본 게임판용. 원본을 보존한다.
- `*-portrait.webp`: 384×384 선택 화면용 8개. `*-swim.webp`: 256×256 게임판용 8개. 합계 294,026 bytes. alpha를 유지한다.
- [manifest.json](manifest.json): 원본/납품 SHA-256, 실제 분리 지점, crop, 크기와 파일 용량.

`tools/prepare-skin-art.js`가 가운데 투명 여백을 찾아 두 이미지를 나누고, 각 실루엣을 정사각형 안에 동일한 여백으로 정렬한다. 이는 잘림 방지와 크기 정규화를 위한 내보내기이며 원본의 모양을 다시 그리거나 색을 덧칠하지 않는다.

```powershell
node tools/prepare-skin-art.js <기존 sharp 설치 경로>
```

## 게임 연결과 호환성

`tools/build-source.js`가 16개 WebP를 모두 내장한다. `src/art.js`는 필요한 스킨/뷰만 한 번 로드하고 재사용한다. 로딩 중/실패 시에는 기존 색상·Canvas 대체 그림으로 계속 동작한다. 준비된 전용 이미지 위에는 기존 평면 무늬를 중복으로 그리지 않는다. 준비 뒤 임시 색상 캐시를 해제하고, 컬렉션·메인 작은 카드·보상 미리보기·게임판을 다시 그린다.

컬렉션은 스킨별 밝은 배경을 사용하고 잠긴 스킨도 본래 색으로 보여 준다. `잠김` 배지, 해금 조건, 비활성 버튼으로 획득 여부를 구분한다. 기존 스킨 ID·획득 조건·소유 목록·선택 저장 형식·게임 규칙은 그대로다. 메인 구명환 마스코트는 기존 대표 이미지다. 메뉴 문구 `수로 골라 하기`는 변경하지 않았다.

단일 웹 HTML은 약 676.8KB에서 1,061.8KB로 증가했다(빌드 도구 표기). 매 프레임 이미지 생성·색상 합성이나 새 장식 파티클을 추가하지 않았다. 실제 기기의 이미지 디코딩/메모리·장시간 성능은 별도 검증 대상이다.

## 검증

- `npm test` 136개 통과. 지연/실패 시 대체 그림, 필요한 뷰만 한 번 로드, 반복 그리기 재사용, 전용 이미지의 중복 장식 방지, 16개 파일 내장/해시, 기존 획득/저장/선택 회귀 검사를 포함한다.
- `npm run verify`: 스토리 48개 + 시험 코스 12개 통과.
- `build`, `build:artifact`, `build:web` 통과. 기본/아티팩트에도 같은 이미지를 내장한다.
- 브라우저 QA에서 실제 렌더러로 8종의 선택 이미지와 32/48px 게임판 이미지를 시각적으로 확인했다. 모바일 390×844에서 8종을 차례로 선택하고 `사용 중` 상태를 확인했다. 별바다 선택 후 새로고침으로 복원됐고, 실제 방향키 6회로 첫 수로 별 3개 클리어를 확인했다.
- QA는 별도 저장 키와 합성 소유 기록을 사용했다. 실제 배포 빌드의 잠긴 스킨은 컬러로 보이면서 선택 불가 상태를 유지한다. 실물 휴대폰 터치·GPU/발열·실제 보상 획득 과정은 이번 브라우저 검증에 포함하지 않았다.

로컬 확인: `node tools/build-skin-qa.js`, `node tools/serve.js . 5178` 후 `http://127.0.0.1:5178/outputs/qa/skin-v2.html`에서 `그림 비교` 또는 `스킨 모두 보기`. 이 페이지의 소유 기록과 검증 버튼은 배포에 포함하지 않는다. 캡처/검사 로그는 무시된 `outputs/qa/skin*-v2*`에 있다.
