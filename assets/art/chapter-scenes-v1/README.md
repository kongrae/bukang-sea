Generated 2026-10-03 with the built-in ImageGen tool for the chapter selection cards in Shark SOS.

- Four separate original PNGs are kept in this folder. Existing chapters 5–6 artwork is unchanged.
- Game derivatives are `assets/art/regions/<name>.webp`, 720 × 480, quality 78; generated by `tools/prepare-region-art.js <sharp path> --chapters-only`.
- All six chapter cards use the same 3:2 layout. Artwork is embedded in standalone HTML, artifact and web/PWA builds.
