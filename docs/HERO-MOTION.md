# 메인 상어·바다·출발 버튼 — 애니메이션 6번

2026-10-01. 기존 메인 상어는 화면 밖에서 출발해 다시 나타날 때까지 빈 바다가 보였고, 전역 시간에 연결돼 화면 복귀 시 위치가 달라졌다. 바다·숭어·부표의 동작은 동작 줄이기에서도 계속됐다.

## 변경

- 메인 전용 시간으로 상어가 바다 영역 안에서 천천히 선회한다. 짧은 항적을 그리며 현재 선택한 상어의 공통 그림을 사용한다. 제목 위 물 영역을 넓혀 일반 배너 높이는 224px, 높이 700px 이하 화면은 204px로 표시한다. 제목·설명 영역 124px은 유지한다.
- 물 영역을 터치하면 0.65초 파문과 짧은 수영 반응을 표시한다. 파문은 최대 4개이며 만료 후 제거한다. 제목/설정 버튼·추가 손가락에는 반응하지 않으며 스크롤을 막지 않는다. 게임 기록·소리·진동에 영향을 주지 않는 장식이다.
- 출발 버튼의 약한 빛이 메인 진입 때 0.7초 동안 한 번 지나간다. 기존 눌림·눌린 깊이 반응과 버튼 문구를 유지하며 게임 진입을 기다리게 하지 않는다.
- 설정·상어 선택·다른 시트가 열리거나 문서가 숨겨지면 메인 수영 시간을 진행하지 않는다. 수로 진입/메인 복귀 때 시간·파문을 초기화한다. 동작 줄이기에서는 상어·숭어·부표·물결을 정적으로 표시하고 파문·버튼 빛을 생략한다.

새 이미지·라이브러리·반복 타이머를 추가하지 않고 기존 Canvas와 프레임 루프를 사용한다. 배너가 40~44px 높아져 첫 화면의 목록 일부는 아래로 이동하지만 세로 스크롤로 계속 접근할 수 있다.

## 검증

- 최종 소스 `npm test` 80개 및 `npm run verify` 전체 48개 수로 통과. 문법·diff 검사 통과.
- 390×844 일반 동작 QA에서 실제 물 터치로 파문 1개/반응 0.65초를 확인했다. 750ms 단계 진행 후 모두 제거되고, 반복 터치 6회에도 4개를 넘지 않았다. 제목 영역 터치는 파문을 만들지 않았다.
- 설정창을 연 뒤 메인 시간이 0.29초로 유지됐다. 선회 장면을 캡처해 상어가 물 영역 안에 표시되는 것을 확인했다. 일반 모드 출발 버튼은 0.7초/1회 연출이며 실제 클릭으로 수로에 즉시 진입하고 복귀 시 시간·잔상이 0으로 초기화됐다.
- 수정 없는 기본 테스트·웹 빌드를 320×568로 확인했다. 출발 버튼은 폭 296px/높이 58px, 아래쪽 위치 약 341px이며 제목은 바다와 겹치지 않는다. 시작·메인 복귀·이어하기가 정상이며 오류 로그는 없었다.
- 실제 브라우저의 동작 줄이기 설정에서 물 터치 전후/시간 경과 후 화면 캡처가 같았고 버튼 빛은 숨겨졌다.
- `build`, `build:artifact`, `build:playtest`, `cap:sync`로 빌드와 Android 웹 자산을 동기화했다. 이번 작업에서 APK/AAB를 생성하지 않았다.

일반 동작 강제와 수동 프레임 버튼은 기록이 격리된 로컬 QA HTML에만 있다. `outputs/qa/motion6-*.png`는 개발자 검증 캡처이며 실물 휴대폰 성능·사람의 재미 평가를 뜻하지 않는다. 전체 연출 성능과 중단 처리 종합 검증은 8번에 남긴다.
