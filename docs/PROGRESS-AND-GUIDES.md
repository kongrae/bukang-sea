# 진행 중 저장과 장치 안내

2026-09-30 개선 작업 4번. 기존에는 최고 별과 마지막 수로 번호만 저장해 새로고침하면 판이 초기화됐고, 새 장치의 규칙은 짧은 안내문과 목록의 범례에 의존했다.

## 이어 하기

- 상어 위치·방향, 먹은 숭어, 설치한 그물, 구조정 위치·방향, 이동 횟수와 되돌리기 기록을 자동 저장한다. 기록은 기존과 같이 최대 200개다.
- 스토리는 하나의 진행 슬롯을 유지한다. 다른 스토리 수로를 시작하면 스토리 슬롯을 교체하며 일일 진행은 유지한다. 콘텐츠 개선 1번부터 구조작전은 세 수로 각각의 진행을 유지하고 이전 단일 수로도 별도로 이어 한다. 저장 호환은 `DAILY-OPERATION.md` 참고.
- 목록의 '이어서 하기'에는 진행 중 스토리 수로와 이동 횟수를 표시한다. 같은 수로의 목록 버튼으로 들어가도 복원한다. 일일 카드도 해당 날짜의 진행을 이어 한다.
- '처음부터'는 그 모드의 진행 상태를 초기화해 저장한다. 클리어하면 해당 슬롯을 삭제하며 최고 별 기록을 유지한다.
- 이동·그물 설치/회수·되돌리기·수로 진입 때 저장한다. 이동 연출 중에는 이미 확정한 도착 위치와 구조정 상태에 해당 경로에서 먹을 숭어를 모두 합쳐 저장한다. 브라우저 화면 이탈·숨김과 Capacitor 비활성화 이벤트에서는 현재 턴을 완료하고 아직 실행하지 않은 대기 입력을 버린다. 탈출 중 이탈하면 클리어 기록도 확정한다.
- 오늘과 날짜가 다른 일일 진행은 이어 하지 않으며 목록에서 정리한다. 날짜별 퍼즐 생성 규칙과 `DAILY_VERSION`은 유지한다.
- 세션 버전, 수로/날짜, 맵과 그물 수, 좌표·숭어·그물·구조정·이동 수·기록 구조를 확인한 뒤 복원한다. 잘못된 세션이나 변경된 맵의 세션은 무시한다. 기존 저장 키 `bukang-sea-v1`과 최고 별·스킨·설정은 유지한다.

저장소 접근 실패는 기존처럼 예외를 잡아 플레이를 계속한다. 저장이 차단되거나 데이터가 삭제되면 기기를 다시 열었을 때의 복원은 보장할 수 없다. 이번 변경은 기기 내 저장이며 기기 간 동기화는 추가하지 않았다.

## 장치 안내

2026-10-01 업데이트: 아래 초기 정지 아이콘 안내는 부표를 포함한 여섯 장치의 짧은 반복 사용 예시로 확장했다. 재생/일시정지/처음부터 보기, 장치별 전환, 열어 본 장치만 확인 기록, 동작 줄이기를 지원한다. 현재 동작과 검증 범위는 [DEVICE-DEMO.md](DEVICE-DEMO.md)를 따른다.

구조정·물줄기·그물·모래톱·소용돌이를 처음 만난 수로에서 해당 장치의 그림과 규칙을 보여준다. '확인'이나 Escape/네이티브 뒤로가기로 닫았을 때 본 것으로 기록하며, 다음 진입에서는 반복하지 않는다. 기존 스와이프·그물 손가락 안내는 유지한다.

설정의 '장치 안내'에서 언제든 다시 읽을 수 있다. 게임 중에는 현재 수로의 장치를, 목록에서는 전체 장치를 보여준다. 장치가 없는 수로에서는 기본 이동·별 획득 규칙을 안내한다. 시트가 열린 동안 뒤의 화면은 입력을 받지 않고 이동 연출도 멈춘다. 안내 목록만 스크롤해 작은 화면에서도 제목과 확인 버튼이 보인다.

## 검증

- `npm test`: 23개 통과. 기존 풀이기·별 판정·90일 일일 퍼즐 호환 11개, 기존 구조정 연출 4개, 진행 복원·장치 안내 8개다.
- 새 검사는 이동 중 재접속 시 전체 숭어 수집, 그물 편집/회수와 되돌리기 복원, 스토리/일일 분리, 날짜 변경, 대기 입력 폐기, 잘못된 세션·맵 변경, 저장 실패를 다룬다. 전체 48개 수로의 해법을 재생하며 각 턴과 그물 편집 상태가 복원 가능한지도 확인한다.
- `npm run verify`: 전체 48개 해법·그물 필요성·역할별 별 기준 통과.
- `npm run build`, `npm run build:artifact`, `npm run build:web`: 모두 통과해 결과물을 갱신했다. 안내에 추가된 글자를 포함하도록 내장 폰트도 다시 생성했다.
- 360×640 실제 브라우저에서 6번 수로의 이동 직후 새로고침 → 3회·숭어 2/2 복원 → 되돌리기 후 2회·숭어 0/2를 확인했다. 탈출 직후 새로고침해 진행 슬롯이 정리되는 것도 확인했다.
- 12번 수로에서 그물을 설치하고 1회 이동한 뒤 새로고침해 남은 그물 1개와 판 배치를 확인했다. 스토리와 일일 수로를 각각 1회 진행한 상태가 함께 유지됐다. '처음부터' 후 재접속하면 0회·그물 2개·되돌리기 불가로 초기화됐다.
- 오늘의 수로도 재접속 후 이어서 9회·별 3개로 클리어했고, 완료 카드로 바뀌며 일일 진행 슬롯이 정리됐다. 기존 스토리 별 36개·보유 스킨 2개는 유지됐다.
- 첫 구조정·물줄기·그물 안내, 확인 후 재접속 시 반복하지 않음, 설정에서 다시 열기, 전체 장치 안내의 작은 화면 배치를 브라우저에서 확인했다.

자동 검사는 실제 게임 함수를 실행하되 캔버스·저장소 일부를 대체한 테스트 환경이다. 물리 휴대폰 터치, Safari, 네이티브 앱 전환/강제 종료와 낮은 성능 기기에서의 저장 지연은 아직 검증하지 않았다. 공개 배포는 수행하지 않았다.
