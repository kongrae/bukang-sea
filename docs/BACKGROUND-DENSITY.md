# 배경의 시각적 밀도 조절 — 디자인 개선 4

## 원인

물 위 반사광과 타일마다 반복되는 물결, 산책로 포장선·나무·구경꾼이 작은 게임판에서도 함께 보였다. 게임에 필요한 상어·숭어·장치보다 먼저 시선을 끌 수 있어 배경 장식의 수와 대비를 낮췄다.

## 변경

- 물 위 반사광 두 겹의 투명도: 0.045/0.025 → 0.02/0.012.
- 작은 물결: 투명도 0.05 → 0.028. 일반 물 타일 중 고정 시드 조건을 만족하는 약 40%에만 그린다. 장치 타일에는 작은 물결을 겹치지 않는다.
- 산책로 포장선은 기존 색의 투명도 0.4로 표시한다. 나무 배치 기준은 내부 0.4 → 0.25, 외부 0.22 → 0.16으로 줄이고 투명도 0.6을 적용한다.
- 구경꾼은 타일 44px 미만에서 생략한다. 큰 타일도 물과 맞닿은 면이 하나인 산책로에만 배치하며 시드 기준 0.4 → 0.18, 투명도 0.65 → 0.4로 줄인다.
- 메인 배너의 물결 투명도: 0.1 → 0.06.

수로 경계의 난간·그림자, 출구 화살표, 상어·숭어·부표·구조정·물줄기·소용돌이·모래톱의 그림은 유지했다. 이동 규칙, 레벨, HUD, 저장 형식은 변경하지 않았다. 움직임 줄이기 설정도 기존 방식으로 적용한다. 외부 이미지나 새 라이브러리를 추가하지 않았다.

## 확인

- 브라우저 360×640의 수로 12 변경 전/후 비교: 타일은 같은 39px이며, 작은 판의 구경꾼이 사라지고 물결·포장선 대비가 낮아진 것을 확인했다.
- 390×844의 수로 12: 타일 53px 유지. 상어·숭어·부표·구조정·물줄기 화살표와 출구를 확인했다.
- 격리된 관찰용 빌드에서 390×844의 수로 37 모래톱과 수로 40 소용돌이를 확인했다. 두 장치의 그림과 첫 장치 안내가 표시된다.
- 메인 배너를 확인하고 원래 기본 스킨·별 36개·수로 13의 0회 진행 상태로 복원했다.
- `npm test` 30개와 `npm run verify` 48개 수로 통과. `build`, `build:artifact`, `build:web`, `build:playtest` 빌드 확인.

화면 비교는 개발자의 브라우저 확인이며, 실제 이용자의 인지 속도나 실물 휴대폰의 시인성·터치를 측정한 결과는 아니다. 실제 이용자 시험 기록은 아직 0명이며 `PLAYTEST.md`의 절차에 따라 관찰해야 한다.

디자인 개선 1~4는 모두 완료했다. 메인 화면은 `MAIN-SCREEN.md`, 상어는 `SHARK-DESIGN.md`, 글자와 목표 표시는 `TEXT-AND-GOALS.md` 참고.
