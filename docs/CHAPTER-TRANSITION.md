# 장 전환 표현 — 2026-10-08

장을 이어서 플레이할 때 장이 바뀌는 순간이 보이지 않던 문제를 고쳤다. 새 그림 없이 이미 있는 지역 그림 6장과 장 소개 문구(`JOURNEY_STORY`)를 다시 사용한다. 저장 형식·별·해금·수로 순서는 바꾸지 않았다.

## 이전 상태

- 장 마지막 수로의 결과창이 일반 클리어와 같은 모양이었다(제목과 이야기 한 줄만 다름).
- 다음 지역 그림은 4→5장, 5→6장에서만 보였다. 이전 시험 코스용 코드가 그 두 지역(`PILOT_REGIONS`)만 알았다.
- "다음 장으로"를 누르면 바로 다음 장 첫 수로와 장치 안내 창이 열렸다. 장 이름·그림·소개를 보여 주는 순간이 없었다.

## 바뀐 흐름

1. **장 끝 결과창**
   - 장의 12개 수로를 모두 구출하면 별 아래에 'N장 완료 · ★ 별 / 36' 도장이 찍힌다. 구조일지 도장과 같은 연출이다.
   - 모든 장 끝에서 다음 지역 그림과 '다음 지역 · N장', 장 이름을 보여 준다. 소개 문구는 다음 장 표지에서 보여 주므로 여기서는 뺐다.
2. **장 표지 (새 화면, `openChapterCard`)**
   - 가운데 카드로 열린다. 지역 그림이 5초 동안 천천히 다가오고, 6개 장과 '바다'로 이어진 여정 위에서 상어가 지난 장에서 이번 장으로 옮겨 간다.
   - 'N장', 장 이름, 소개 한 줄, '새 장치 · 이름'(범례 그림)을 차례로 보여 주고 'N장 시작' 버튼을 둔다.
   - 버튼이나 카드 아무 곳을 누르거나 Esc·뒤로 가기를 누르면 시작한다. 연 지 0.45초 안의 입력은 무시한다. "다음 장으로"를 두 번 눌러 바로 넘어가지 않게 하기 위해서다.
3. **이어지는 순서**
   - 표지가 열려 있는 동안 수로는 뒤에 이미 준비돼 있다. 시작 소리와 장치 안내는 표지를 닫을 때 나온다(`enter(..., held)`).
   - 그다음 장치 칸 강조(F5)가 이어진다.

## 언제 보이나

- 2–6장의 첫 수로에 들어갈 때만 보인다. "다음 장으로"와 목록·이어서 구출 버튼 모두 해당한다.
- 1장은 게임 시작이라 보이지 않는다. 6장이 끝나면 기존 구출 엔딩이 나온다.
- 다음 경우에는 보이지 않는다.
  - 그 수로를 이미 깬 경우
  - 같은 앱 실행에서 이미 본 경우(메모리에만 기록하며 저장하지 않는다)
  - '처음부터'로 다시 할 때
  - 이미 이동한 판을 이어서 할 때
- 동작 줄이기에서는 같은 화면을 움직임 없이 보여 준다.

## 소리

`sfx.chapter()`는 기존 녹음만 쓴다(새 음원 없음): 물살 → 마림바 C#5–E5–A5 → A5 종. 음량은 별·해금과 같은 보상 단계에 맞췄다. 음소거·백그라운드에서는 다른 보상음처럼 멈추고, 녹음을 읽지 못하면 합성음으로 대신한다. 비교실(`npm run build:sound-lab`)에 '장 시작' 항목을 추가했다.

## 검증

- `npm test` 174개 통과. 새 테스트 3개:
  - 장 표지 조건: 2–6장 첫 수로에서만, 앱 실행당 한 번, 깬 수로·이동한 이어하기·다시 하기 제외. 표지가 있을 때 시작 소리·장치 안내를 미룸.
  - 장별 새 장치: 1장 물줄기 ~ 6장 스위치·수문
  - 장 표지 소리: 물살 + 음높이 554·659·880Hz + 나중의 종, 합성음 대체, 음소거
- 결과창 테스트 갱신: 1장 끝 도장 '1장 완료 · ★ 12 / 36', 다음 지역 미리보기, 오늘의 수로에서는 둘 다 없음
- `npm run verify` 72개 + 이전 시험 코스 12개 통과. 단일 HTML·아티팩트·웹/PWA 빌드 통과
- 헤드리스 Edge(390×844, 웹 빌드):
  - 1장 마지막 수로를 별 3개로 깨면 '1장 완료 · ★ 36 / 36' 도장과 2장 그림 미리보기가 보였다.
  - "다음 장으로" 뒤 표지가 열리고, 0.2초 만의 두 번째 탭은 무시됐다. 상어는 2장 칸 위에서 멈췄고(중심 차 0px) 버튼에 포커스가 갔다.
  - 시작하면 구조정 안내 창이 열렸다. '처음부터'와 목록에서 다시 들어갈 때는 표지가 나오지 않았다.
  - 2–6장 표지 다섯 개 모두 그림(720×480)·장치 이름이 맞았다. 360×640 화면에서도 6장 표지가 스크롤 없이 들어갔다(553px).
  - 동작 줄이기에서는 정지 화면으로 같은 흐름이었다. 콘솔 오류는 없었다.
- 실물 휴대폰의 체감과 소리는 확인하지 않았다.
