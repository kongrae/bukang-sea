## 확인한 기존 구조

기준 커밋은 `def8fd47bc50a4274a4380424fd08c915b2edee7`이다. `game.js`의 `tone`/`noise`가 각 이벤트에서 직접 출력으로 연결됐다. 숭어와 스위치에 사각파를 사용했고, 그물 설치/회수는 같았으며 이동음 길이는 고정됐다. 노이즈 버퍼는 매번 생성됐고 동시 재생 상한·공통 출력 제어·재생 중인 음 취소가 없었다. 별의 JS 타이머는 정리했지만 이미 예약한 오디오 노드는 음소거 시 취소하지 않았다. 일반 버튼/시트/시작/구조정/해금 전용 소리는 없었다.

기존 게임의 이동을 브라우저에서 실행하고 이벤트·재생 소스를 추적했다. 제공된 도구는 브라우저의 스피커 출력을 모델에 전달하지 않는다. 따라서 직접 들었다는 평가, 청취 피로도 개선, 실제 휴대폰의 낮은 볼륨에서의 구별 가능성을 확정하지 않는다. 아래 수치는 실제 Web Audio 렌더링과 자동 조작의 결과다.

## 소리와 연결

| 행동 | 음색/의도 | 실제 연결 |
|---|---|---|
| 이동·정지 | 무음 (사용자 요청으로 제거) | 일반 헤엄 출발·정지 효과음과 합성 함수를 제거했다. 이동·도착의 시각 효과와 장치·획득·탈출 소리는 유지한다. |
| 막힘 | 작고 낮은 토이 ‘톡’ | 실제 경로가 없는 이동 시도; 180ms 간격 제한 |
| 숭어 | 사인파 물방울, 한 이동 안에서 A4–C5–D5–E5 상승 | `eatFish`; 연속 번호는 다음 이동에서 초기화, 음량은 고정, 마지막 숭어에 E5/A5 마무리 |
| 그물 | 설치는 펼침+상승하는 퐁, 회수는 접힘+하강하는 물방울 | `tapTile`에서 성공한 설치/회수만 호출; 실패한 탭은 무음 |
| 물줄기·소용돌이 | 짧은 물살 전환 / 내려갔다 올라오는 둥근 음과 물살 | 실제 통과 시점, 각 경로 이벤트당 한 번 |
| 모래톱 | 저역으로 닫히는 젖은 마찰음 | 해당 칸에서 멈출 때 |
| 스위치·수문 | 둥근 삼각파 버튼음 / 낮은 토이 기계음+물살 | 실제 스위치 도착, 수문음은 내부에서 45ms 뒤 시작 |
| 구조정 | 작고 짧은 물살 | 상어와 수문 다음의 구조정 이동 시작; 위치가 바뀔 때만, 전체 구조정에 한 번, 380ms 제한 |
| 탈출·별 | 짧은 물보라와 A 장조 계열 A4–C#5–E5 | 탈출 연출 / 기존 별 등장 타이머와 일치, 동작 줄이기에서는 짧은 완료 구절 |
| 스킨 해금 | A4–E5–A5의 특별한 마무리 | 실제 새 스킨 보상이 있을 때 별 구절 뒤 960ms; 나가면 취소 |
| UI·시작·선택 | 짧은 나무/실리콘 타격, 시작과 선택은 두 음 물방울 | 버튼의 확정 클릭, 실제 수로 진입, 실제 스킨 변경 |
| 시트 | 아주 짧은 공기/물살 | 실제 열림/닫힘에 한 번; 드래그 중·취소된 드래그는 무음; 결과 시트는 보상음과 경쟁하지 않음 |

전체 음색은 사인파/삼각파와 부드러운 노이즈를 사용한다. 3.4kHz 공통 저역 통과 필터, 짧은 어택/릴리스, ±1.25% 피치 변주를 적용한다. 강한 고역 사각파나 긴 잔향은 사용하지 않는다. 작은 UI 소리보다 획득과 구출이 앞에 들리도록 그룹 음량을 조절한다.

## 재생·믹싱·수명

- `src/sound.js`의 `createGameAudio()`를 기존 `ac()`/`sfx` 경로로 연결한다. 새로운 라이브러리는 없다.
- 컨텍스트 1개, 1초짜리 노이즈 버퍼 1개를 재사용한다. 발음마다 필요한 일회성 소스는 종료 시 `onended`로 연결을 해제한다.
- 동시에 유효한 효과는 6개까지, 우선순위 교체 중 끝맺는 짧은 음까지 포함해 8개 이하다. 낮은 우선순위를 줄이거나 생략하며, 획득/보상 때 기존 주변 음을 낮춘다.
- 연속 숭어는 주파수·볼륨·밀린 예약 길이를 제한한다. 거친 프레임에서 동시에 여러 마리를 먹어도 120ms보다 길게 누적하지 않는다.
- 컴프레서와 출력 여유를 두고, 각 음은 0에서 시작해 0으로 끝나는 엔벌로프를 쓴다. 취소는 18ms 안에서 부드럽게 끝낸다.
- 신뢰된 클릭/키/기존 게임 입력 이후에만 컨텍스트를 만든다. 오디오 미지원이나 재개 거절은 입력·게임 진행에 예외를 던지지 않는다.
- 음소거는 현재/미래 노드를 모두 정지시키고 보상 세대 번호를 바꾼다. 도중에 다시 소리를 켜도 이미 취소된 별/해금 타이머가 소리를 되살리지 못한다. 시각적 보상과 저장은 계속된다.
- 새 판/타이틀 진입은 이전 음을 정리한다. 앱·페이지·문서 비활성화 시 재생을 정리하고 컨텍스트를 중단한다. 복귀는 지난 효과음을 재생하지 않는다.
- 같은 스킨/선택 항목을 다시 선택해도 일반 탭을 덧붙이지 않는다. 구체적인 시작·선택·시트 소리가 있으면 일반 버튼음을 중복 재생하지 않는다.

## 비교실 사용

```powershell
npm run build:sound-lab
node tools/serve.js . 5178
```

`http://127.0.0.1:5178/outputs/audio/index.html`에서 행동별 전후 재생, 같은 13초 순서의 A/B, 음소거/중단, 전후 WAV 생성, 밀집 재생 파형 검사를 제공한다. `game-after.html`은 별도의 `bukang-audio-qa-after` 저장 키와 화면에 보이는 검사 버튼으로 실제 규칙을 305초 동안 자동 조작한다. 배포용 파일에는 개발 버튼과 테스트 저장 키가 포함되지 않는다.

기준은 빌드 스크립트에 커밋으로 고정되어 재현할 수 있다. WAV는 비교실에서 직접 만드는 검증 산출물이며 출시 오디오 자산이 아니다. 생성 페이지/WAV/검사 로그는 무시된 `outputs/audio/`에 있다.

## 검증

아래 파형 수치와 305초 플레이 기록은 최초 사운드 개편(`767dc37`) 당시 결과다. 이후 사용자 요청으로 일반 헤엄·정지 소리만 제거했으며, 현재 비교실의 개선 세트에서도 두 행동은 무음이다.

- 자동 검사는 기존 규칙·진행·보상 검사에 컨텍스트/버퍼 재사용, 음소거/예약 취소, 반환 후 미재생, 상한/스로틀, 합법적인 그물 편집, 획득 연속 번호, 구조정 시점, 해금 지연 취소를 더한다.
- 실제 Chromium `OfflineAudioContext`, 48kHz mono로 13초 전후 순서를 렌더링했다. 개선본 피크 **0.184039 (-14.70dBFS)**, 클리핑 샘플 **0**, 마지막 200ms 최대 진폭 **0**, 종료 후 남은 소스 **0**이었다. 이전본 피크는 0.160105였다. 두 세트의 이벤트 구성/음량이 다르므로 RMS 차이를 청취 품질 점수로 해석하지 않는다.
- 인접 샘플 최대 차이는 이전 0.059666, 개선 0.017457이었다. 이는 수치상 불연속 위험을 줄였다는 지표이며 ‘클릭 노이즈가 귀에 들리지 않는다’는 청취 판정은 아니다.
- 40ms마다 이동·막힘·그물·장치·획득·별을 몰아 넣은 5초 스트레스 파형은 피크 **0.308906 (-10.20dBFS)**, 클리핑 **0**, 동시 효과 최대 **7**, 음소거 후 끝 구간 **0**, 남은 소스 **0**이었다. 과도한 이벤트 611개를 의도적으로 제한했다.
- 사운드 코드는 `build-source.js`로 단일 HTML·아티팩트·웹/PWA에 내장된다. 오디오 파일 요청이나 네트워크 의존성은 없다. PWA 캐시 해시는 소스 변경을 포함한다.

- `npm test` **151/151**, `npm run verify` **스토리 48 + 시험 수로 12**를 통과했다. 단일 HTML·아티팩트·웹/PWA 빌드를 완료했고 출시 파일에 개발 검사 UI가 없음을 확인했다.
- 실제 브라우저에서 **305.7초**, 실제 규칙으로 **439회 이동·61회 구출**을 자동 실행했다. 이동·막힘·숭어·그물·물줄기·소용돌이·모래톱·스위치·수문·구조정·별·해금 경로를 검사했다. 장시간 실행의 동시 효과 최대는 **5**, 종료 후 남은 효과/소스는 **0**, 노이즈 버퍼는 **1개**였다. 브라우저 오류/경고는 없었다.
- 위 자동 플레이의 게임 `step()` CPU 시간은 평균 **0.051ms**, 최대 **2.8ms**였다. 렌더링 프레임률이나 휴대폰 터치 지연 측정값은 아니다.
- 실제 설정에서 소리를 끄고 새로고침해 꺼짐이 유지되는 것을 확인했다. 다시 켠 뒤 앱 중단 모의에서 컨텍스트 `suspended`, 소스 **0**을 확인했고 복귀 후 `running`으로 돌아와도 재생 수가 증가하지 않았다. 화면 이탈 시 정리와 별/해금 도중 이탈의 예약 취소는 자동 검사로 확인했다.

직접 청취, 실제 휴대폰 저볼륨/장시간 피로, Safari 및 네이티브 앱의 오디오 라우팅은 이번 도구로 확인할 수 없는 범위다. 5분 검증은 실제 게임 규칙의 자동 조작이며 청취 평가가 아니다.
