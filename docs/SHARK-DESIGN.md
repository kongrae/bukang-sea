# 디자인 개선 2 — 상어 디자인 강화

2026-09-30. 작은 게임판에서 가는 몸통과 납작한 등지느러미 때문에 숭어와 인상이 비슷하던 상어를 개선했다.

## 변경

- 머리와 몸통을 넓히고 몸길이를 조금 줄여 머리/몸통/꼬리의 비율을 구분했다.
- 가슴지느러미를 뒤로 뻗는 삼각형으로 정리하고, 꼬리는 좁은 연결부와 깊게 갈라진 형태를 강조했다.
- 등지느러미를 삼각형 면과 밝은 모서리로 그린다. 양쪽 아가미 세 줄과 밝은 눈 테두리를 추가했다.
- 기존 밝은 외곽선과 스킨 색/무늬/장식을 공통 `drawShark()`에 적용한다. 게임판·메인 배너·스킨 미리보기가 같은 그림을 사용한다.
- 꼬리 흔들림은 움직임 줄이기 설정을 따른다. 스킨 장식의 Canvas 상태를 저장/복원해 장식이 이후 눈의 투명도에 영향을 주지 않도록 했다.

외부 이미지나 새 이미지 생성 모델을 사용하지 않고 기존 Canvas 도형을 수정했다. 저장 데이터와 스킨 획득 기준, 이동 규칙, 레벨 구성은 변경하지 않았다.

## 확인

- 기존 커밋의 `drawShark()`와 변경 후 함수를 같은 크기로 그린 정적 비교: 타일 28/41/55/80px, 숭어와 나란히 비교.
- 같은 렌더링 함수로 스킨 7종의 원래 색/무늬/장식, 상하좌우 방향, 이동 시 늘어남/정지 시 눌림 형태를 확인했다. 이 비교는 게임 내 스킨 획득을 증명하는 시험이 아니다.
- 브라우저 360×640의 수로 12와 스킨 선택 화면, 390×844의 벚꽃 스킨 이동/되돌리기/목록 복귀를 확인했다. 확인 후 원래 기본 스킨과 수로 13의 0회 진행 상태로 돌려놓았다.
- `npm test` 30개, `npm run verify` 48개 수로 통과. `build`, `build:artifact`, `build:web` 빌드 확인.

실물 휴대폰의 시인성·터치와 실제 이용자가 상어/숭어를 얼마나 빨리 구분하는지는 별도 관찰이 필요하다.

디자인 개선 3(작은 글자/목표 표시)과 4(배경의 시각적 밀도 조절)는 완료했다. `TEXT-AND-GOALS.md`, `BACKGROUND-DENSITY.md` 참고.
