# 디자인 개선 3 — 작은 글자와 목표 표시

2026-09-30. 수로 이름의 작은 글자/말줄임, 게임 상단의 비슷한 작은 정보 캡슐 때문에 목표와 진행 상태를 읽기 어려운 문제를 개선했다.

## 변경

- 수로 이름: 11.5px → 13.5px, 밝은 글자와 두 줄 공간으로 표시. 긴 이름도 단어 단위로 줄바꿈한다.
- 챕터 별/잠김: 11.5px → 13px. 이어할 수로와 오늘의 수로/스킨 보조 정보: 13px → 14px. 게임 수로 번호/역할: 12px → 13px. 안내: 13.5px → 14px.
- 상단 정보 순서: 숭어 목표 → 이동 횟수/기준 → 남은 그물. 목표에 아이콘/밝은 테두리와 18px 숫자를 사용한다. 숭어 없는 판은 '목표 · 바다로 탈출'을 표시한다.
- 전체 숭어 수집 시 '숭어 완료'와 금색 숫자로 표시하며, 되돌리면 해당 상태도 복원한다. 이동 기준을 넘으면 이동 숫자가 기존 주황색으로 바뀐다.
- 이동 숫자와 숭어 숫자의 변화 애니메이션을 종류별 DOM 요소에 연결해 정보 순서 변경 후에도 알맞은 숫자에 적용한다.

폰트 종류, 별 획득 규칙, 이동 기준, 저장 기록 형식은 유지한다. 숭어 수집은 별 보너스이며, 숭어를 남겨도 탈출할 수 있다.

## 확인

- 360×640: 긴 이름 '친수공원 한복판'은 13.5px 두 줄로 표시되고 가로 넘침이 없다. 첫 8개 수로가 화면에 보인다.
- 390×844: 해당 챕터의 12개 수로가 첫 화면에 보이며, 가로 넘침이 없다.
- 수로 12 타일 크기: 360×640에서 41 → 39px, 390×844에서 55 → 53px. HUD가 커진 만큼 타일은 2px 줄어든다.
- 320×568: 숭어 목표/이동/그물 정보를 한 줄의 세 영역에 표시하며 각 영역의 글자에 가로 넘침이 없다.
- 격리된 테스트 빌드의 수로 3에서 U/R/U 입력으로 숭어 1/1, '숭어 완료', 금색 숫자를 확인했다. 되돌리기 후 0/1로 돌아왔다.
- 격리된 수로 1에서 탈출 목표와 이동 9/기준 8회 초과의 주황 숫자를 확인했다.
- 수로 12의 그물 설치/되돌리기로 남은 그물 2 → 1 → 2를 확인했다. 확인 후 기본 스킨과 원래 수로 13의 0회 진행으로 복원했다.
- `npm test` 30개와 `npm run verify` 48개 수로 통과. 내장 폰트 재생성 및 `build`, `build:artifact`, `build:web` 확인.
