# 장치 사용 예시 팝업

2026-10-01: 기존 첫 장치 안내의 정지 아이콘을 짧은 반복 애니메이션으로 교체했다. 영상 파일을 다운로드하지 않고 기존 상어·장치 그림으로 사용법을 재생하므로 웹/PWA/Capacitor에 동일하게 포함된다.

## 표시와 조작

- 부표·구조정·물줄기·그물·모래톱·소용돌이를 처음 만난 수로에서 자동으로 팝업을 연다. 각 예시는 약 3.6–7.6초이며 손가락 표시, 단계별 설명, 진행 막대와 함께 반복된다.
- 여러 새 장치가 함께 나오면 `다음 장치 보기` 또는 장치 이름 버튼으로 하나씩 볼 수 있다. `일시정지`, `재생`, `처음부터 보기`를 제공하며 시청 완료를 강제하지 않는다.
- 설정 → 장치 안내에서 다시 볼 수 있다. 게임 안에서는 해당 수로의 장치, 메인에서는 여섯 장치를 모두 제공한다. 장치가 없는 수로에서는 기본 이동 예시를 보여준다.
- 닫기·확인·Escape·Android 뒤로가기는 실제로 열어 본 장치만 기존 `seenDevices`에 기록한다. 미열람 장치를 함께 확인 처리하지 않는다. 기존에 확인한 장치 기록과 게임 진행은 유지한다.
- 시스템의 동작 줄이기가 켜져 있으면 이동 경로와 최종 상태를 정지 화면으로 보여준다. 사용자가 재생/처음부터 보기를 누르면 해당 예시만 재생한다. 탭을 숨기거나 팝업을 닫으면 예시 시간은 진행하지 않는다.
- 작은 화면에서는 내용 영역만 스크롤하며 닫기와 확인 버튼은 바깥에 남는다.

## 예시 내용

| 장치 | 보여주는 동작 |
|---|---|
| 부표 | 부표 앞에서 멈추고 다른 방향으로 이동 |
| 구조정 | 상어 이동 → 정지 → 구조정 한 칸 이동, 벽에서 방향 전환 |
| 물줄기 | 화살표 방향으로 꺾인 뒤 계속 이동 |
| 그물 | 빈 칸 설치 → 앞에서 정지 → 회수 → 다른 칸에 재사용; 편집 시 이동 수 유지 |
| 모래톱 | 모래톱 위에 정지 → 다음 스와이프로 다시 출발 |
| 소용돌이 | 짝으로 순간 이동 → 같은 방향으로 계속 이동 |

`src/device-demo.js`가 독립된 작은 맵과 실제 `slide()`·`stepBoats()`로 예시의 이동을 계산한다. 화면은 `sampleDeviceDemo()`가 반환하는 상태를 그린다. 소용돌이는 출발/도착 지점에서 작아졌다 커지며 중간 벽을 가로질러 헤엄치지 않는다. 게임의 프레임 루프와 그리기 함수를 재사용하고 플레이 중인 `g`/`st`, 세션, 별, 힌트 사용량은 건드리지 않는다. 저장 키와 기존 생성기·48개 레벨은 유지한다.

## 검증

- `npm test` 67개 통과. 새 6개 검사는 일곱 예시의 합법적인 이동·그물 편집, 구조정의 이동 순서/반전, 소용돌이 점프, 예시 상태 불변성, 재생/정지/반복, 미열람 장치 기록, 동작 줄이기, 메인/게임 내 안내 범위를 검사한다.
- `npm run verify` 기존 48개 수로 통과. 이전 일일 맵 호환과 자유 수로 900개 검사도 기존대로 통과했다.
- 브라우저의 실제 동작 줄이기 설정에서 자유 수로 첫 부표 팝업의 정지 경로, 수동 재생·일시정지·닫기, 이동 0회/힌트 두 회 유지, 새로고침 후 자동 팝업을 반복하지 않음을 확인했다.
- 자동 재생은 기록을 격리한 관찰용 빌드에서 동작 줄이기만 해제한 시험 화면으로 확인했다. 수로 6에서 부표만 보고 닫은 뒤 다시 들어가면 미열람 구조정만 소개하는 것을 확인했다. 이 시험 빌드는 공개 배포에 포함하지 않는다.
- Chrome 390×844에서 여섯 장치 선택과 소용돌이 장면을 확인했다. 320×568에서는 애니메이션 영역이 줄어들지 않도록 그리드 행의 높이를 내용 기준으로 유지했다. 내용 스크롤 후에도 닫기(46px)와 다음/확인(56px)이 화면 안에 남고, 재생 버튼은 44px이며 가로 넘침이 없음을 확인했다. 그물의 일시정지/처음부터 보기, 다음 모래톱으로 전환도 실제 버튼으로 검사했다. 브라우저 오류 로그는 없었다.
- 마지막 문구·레이아웃 수정 후 장치/진행 복원/관찰용 빌드 관련 25개 검사를 다시 통과했다. 웹·아티팩트 빌드 및 Capacitor Android 파일 동기화를 수행했다.

실물 휴대폰, Safari 및 Android 네이티브 뒤로가기는 이 작업에서 직접 조작하지 않았다. 브라우저 크기 변경과 자동 검사 결과를 실물 기기 검증으로 보지 않는다.
