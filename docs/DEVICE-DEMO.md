# 장치 사용 예시 팝업

2026-10-08 첫 10분 개선: 부표처럼 단순한 장치는 처음 만나도 이 팝업을 자동으로 열지 않는다(`DEVICE_GUIDES`의 `light`). 대신 판에서 그 칸들이 장치 칸 강조와 같은 금색 고리로 세 번 빛나고, 수로 안내 줄에 장치 설명이 힌트 색으로 나온다. 설명은 첫 이동 뒤 원래 안내로 돌아간다. 강조가 시작될 때 `save.seenDevices`에 기록되며, 동작 줄이기에서는 강조 없이 안내 줄만 보이고 바로 기록된다. 설정의 '장치 안내'에는 그대로 있다. 이전에는 2번 수로(게임 시작 1~2분)에서 설명 5단계·재생 20초짜리 팝업이 열렸다.

2026-10-03 읽기 속도와 그물 구분 개선: 설명이 0.5–1.5초 만에 바뀌던 자동 반복을 없앴다. 기본은 정지 상태에서 문장을 직접 넘기고, 선택 재생은 문장별 읽기 시간을 확보한 뒤 요약에서 종료한다. 아래 조작 설명은 이 버전을 기준으로 한다.

2026-10-02 추가: 시험 코스의 `스위치·수문` 예시(6.6초)를 일곱 번째 장치로 넣었다. 닫힌 수문 앞 스위치에서 멈춤 → 스위치가 눌리고 연결된 수문이 열리는 전환 단계 → 열린 수문 통과를 `slide`·`pressSwitch`·`stepBoats` 실제 재생으로 보여 준다. 메인의 장치 안내는 일곱 장치를 보여 준다. 규칙은 [CONTENT-PILOT.md](CONTENT-PILOT.md).

2026-10-01: 기존 첫 장치 안내의 정지 아이콘을 짧은 반복 애니메이션으로 교체했다. 영상 파일을 다운로드하지 않고 기존 상어·장치 그림으로 사용법을 재생하므로 웹/PWA/Capacitor에 동일하게 포함된다.

## 표시와 조작

- 새 장치를 처음 만난 수로에서 팝업을 열되 자동 재생하지 않는다. `이전 설명`·`다음 설명`으로 이동하며 설명 번호를 표시한다. 수동으로 넘기면 해당 동작을 완료한 정지 장면을 보여 준다.
- `예시 재생`·`일시정지`·`처음부터 재생`을 제공한다. 서로 다른 문장은 최소 4초, 긴 문장은 글자 수 × 0.12초 + 1초 동안 표시한다. 움직임 자체를 느리게 늘이지 않고 끝 장면에 읽기 시간을 추가한다. 재생은 요약에서 멈추며 자동 반복하지 않는다. 정지 뒤 재생은 현재 문장의 시작부터 다시 보여 준다.
- 여러 새 장치는 `다음 장치 보기` 또는 가로로 넘기는 장치 탭에서 선택한다. 장치 전환 시에는 다시 정지 상태로 시작한다. 시청 완료를 강제하지 않는다.
- 설정 → 장치 안내에서 다시 볼 수 있다. 게임 안에서는 해당 수로의 장치, 메인에서는 일곱 장치를 모두 제공한다. 장치가 없는 수로에서는 기본 이동 예시를 보여준다.
- 닫기·확인·Escape·Android 뒤로가기는 실제로 열어 본 장치만 기존 `seenDevices`에 기록한다. 미열람 장치를 함께 확인 처리하지 않는다. 기존에 확인한 장치 기록과 게임 진행은 유지한다.
- 시스템의 동작 줄이기가 켜져 있으면 정지 화면에 이동 경로도 표시한다. 사용자가 재생을 누르면 해당 예시만 재생한다. 탭을 숨기거나 팝업을 닫으면 예시 시간은 진행하지 않는다.
- 작은 화면에서는 예시/상세 내용만 스크롤하며 설명 문장, 이전/다음 설명, 닫기와 확인 버튼은 바깥에 남는다. 설명은 16px, 줄 간격 1.65이며 조작 버튼은 최소 44px이다.

## 그물 수로 구분

- 스토리와 시험 코스의 열린 수로 버튼에 `그물 1개` / `그물 2개` 또는 `그물 없음`을 표시한다. 배지의 금색/중립색 외에 문구로도 구분한다.
- 2026-10-08: 위쪽의 전체 폭 그물 안내 칸(높이 54px)을 없애고, 아래 도구 줄(되돌리기·처음부터·힌트) 맨 오른쪽에 동그란 그물 버튼(`#netTool`)을 둔다. 모든 모드가 같은 자리를 쓴다.
  - 이전에 HUD 칩으로 시험했을 때 눈에 띄지 않아 그물 유무를 모르고 플레이했다는 사용자 관찰이 있었다. 그래서 판 근처의 크고 색이 다른 원형 버튼과, 수로마다 나오는 말풍선을 함께 쓴다.
  - 판 위에 띄우는 안은 시험해 보고 뺐다. 물 칸·출구를 가리지 않는 모서리가 없는 그물 수로가 390×844에서 18개 중 5개, 360×640에서 12개였다.
  - 그물 수로: 금색 원형 버튼에 그물 그림과 빨간 숫자(남은 개수)를 보여 준다. 누르면 그물 사용법이 열린다.
  - 처음 하는 판에서는 말풍선 '그물 N개를 쓸 수 있어요 · 빈 물 칸을 톡!'이 다른 도구 버튼 위를 덮고 그물 버튼을 가리킨다. 첫 이동·그물 편집이나 말풍선을 누르면 사라지고, 되돌려도 다시 나오지 않는다. 첫 그물 수로에서는 장치 칸 강조와 함께 버튼이 빛난다.
  - 그물 없는 수로: 그물을 한 번 만난 뒤(`seenDevices`에 `net`)에는 같은 자리에 회색 점선 '없음' 버튼을 둔다. 누르거나 물 칸을 누르면 '이 수로에는 그물이 없어요. 화면을 밀어서 길을 찾아요.'를 보여 준다. 그물을 만나기 전(1~2장)에는 버튼을 숨기고 도구 줄은 세 칸이다.
  - 그물 수로에서 그물을 한 번도 치지 않은 채 막히면, 막힘 안내가 힌트 대신 그물 버튼을 반짝이고 '그물 N개를 쓸 수 있어요. 빈 물 칸을 눌러 보세요.'를 보여 준다.
  - 사용법 창을 닫으면 그물 버튼으로 초점이 돌아온다. 버튼 때문에 이동이나 그물 편집이 실행되지는 않는다.
- 설치·회수·되돌리기·진행 복원·재시작은 기존 상태로부터 표시를 갱신한다. 새 저장 필드, 레벨 변경, 추가 효과음, 매 수로마다 강제로 열리는 팝업은 없다.

## 예시 내용

| 장치 | 보여주는 동작 |
|---|---|
| 부표 | 부표 앞에서 멈추고 다른 방향으로 이동 |
| 구조정 | 상어 이동 → 정지 → 구조정 한 칸 이동, 벽에서 방향 전환 |
| 물줄기 | 화살표 방향으로 꺾인 뒤 계속 이동 |
| 그물 | 빈 칸 설치 → 앞에서 정지 → 회수 → 다른 칸에 재사용; 편집 시 이동 수 유지 |
| 모래톱 | 모래톱 위에 정지 → 다음 스와이프로 다시 출발 |
| 소용돌이 | 짝으로 순간 이동 → 같은 방향으로 계속 이동 |

`src/device-demo.js`가 독립된 작은 맵과 실제 `slide()`·`stepBoats()`로 예시의 이동을 계산한다. 화면은 `sampleDeviceDemo()`가 반환하는 상태를 그린다. 소용돌이는 출발/도착 지점에서 작아졌다 커지며 중간 벽을 가로질러 헤엄치지 않는다. 게임의 프레임 루프와 그리기 함수를 재사용하고 플레이 중인 `g`/`st`, 세션, 별, 힌트 사용량은 건드리지 않는다. 저장 키와 기존 생성기·48개 레벨은 유지한다.
