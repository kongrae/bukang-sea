# 개인 개발자 계정 인증에서 첫 출시까지

2026-10-01 Google 공식 도움말 확인 기준. 사용자가 제공한 화면은 신분증 제출 후 Google의 신원 확인이 진행 중이고, Android 기기·연락처 전화번호 인증이 남아 있는 상태다. 제출 완료와 신원 승인 완료는 다르다.

## 계정 설정

1. Play Console 홈의 Android 기기 인증 ‘세부정보 보기’를 연다. QR로 Play Console 모바일 앱을 설치/실행하고 개발자 계정을 만든 Google 계정으로 로그인한다. 개발자 계정을 선택해 인증한다. 루팅하지 않은 Android 10 이상 실물 휴대기기를 사용한다. 기기의 전화번호가 계정 연락처와 같을 필요는 없다.
2. Google 신원 승인 메일과 Console 상태를 확인한다. 개인 계정은 신원·기기 확인이 완료돼야 연락처 전화번호 인증을 진행할 수 있다.
3. 국제 형식의 전화번호를 입력하고 문자 또는 음성 전화의 6자리 코드를 인증한다. 한국 휴대전화 `010-1234-5678`의 예시는 `+821012345678`이다. 이 번호는 예시이며 사용자 번호가 아니다.

계정 검증은 Google Play 게시에 필요한 조건이다. 앱 초안 만들기·파일 준비와 정식 게시는 별도 단계이며, 인증 대기 중 Console에서 허용되는 초안 작업을 준비할 수 있다.

공식 자료: [신원·연락처 확인](https://support.google.com/googleplay/android-developer/answer/10841920?hl=ko), [Android 기기 확인](https://support.google.com/googleplay/android-developer/answer/14316361?hl=ko).

## 이 게임의 다음 순서

1. 앱 만들기: ‘상어 SOS: 바다로 보내줘!’, 한국어, 게임, 무료 여부 등 등록 정보를 입력한다. 현재 앱 ID는 `kr.hongrae.sharksos`이며 첫 업로드 후 패키지 이름은 바꿀 수 없다.
2. 실물 기기 검증과 서명된 출시 AAB 준비: `npm run android:release`가 `android/app/build/outputs/bundle/release/app-release.aab`를 만든다. 이는 준비 명령이며 이번 애니메이션 6번 작업에서는 AAB를 새로 만들지 않았다. 기존 업로드 키를 사용하고 실제 Console 업로드 이력에 맞춰 `versionCode`를 증가시킨다. 키·비밀번호는 저장소에 올리지 않는다.
3. 내부 테스트: Console의 테스트 및 출시 → 테스트 → 내부 테스트에서 AAB와 테스터 이메일을 등록하고 설치 링크로 휴대폰에서 테스트한다. 내부 테스트는 최대 100명이며 앱 설정이 완성되기 전에도 시작할 수 있다. 계정 인증 완료 조건과 앱 설정 조건은 별개다.
4. 앱 설정: 스토어 설명·아이콘·스크린샷·그래픽 이미지·연락처, 개인정보처리방침, 데이터 보안, 광고 여부, 앱 접근 권한, 콘텐츠 등급·대상 연령 등 대시보드 항목을 실제 앱/SDK 동작에 맞게 작성한다.
5. 2023-11-13 이후 생성한 개인 계정은 비공개 테스트에서 최소 12명의 테스터가 14일 연속 참여해야 프로덕션 권한을 신청할 수 있다. 이메일 등록만으로 참여가 되지는 않으며 테스터가 참여 링크로 가입해야 한다. 실제 사용·피드백·수정 내용을 기록한다. 내부 테스트 기간은 이 요건을 대신하지 않는다.
6. 요건 충족 후 앱 대시보드에서 프로덕션 액세스를 신청하고 테스트 과정·피드백·개선·준비 상태를 답한다. 승인을 받으면 프로덕션 출시를 생성해 앱 검토를 요청한다. 테스트 기간 충족이 자동 출시를 뜻하지 않는다.
