# 그물 규칙: 한 번 친 그물은 고정 — 2026-10-08

상태: **적용 완료.** 사용자 결정(2026-10-08): 그물을 공짜로 걷었다가 다시 칠 수 있어 '만능 아이템'처럼 느껴진다 → "걷기 불가"로 바꾼다.

## 왜 바꿨나

이전 규칙은 이동 전마다 그물을 공짜로 걷고 다시 칠 수 있었다. 스토리 그물 수로 18개에서 상어가 멈출 수 있는 칸을 세면:

| | 멈출 수 있는 칸 (물 칸 대비) |
|---|---|
| 그물 없이 | 2–40% |
| 그물 1개를 마음대로 옮길 때 | 76–98% |

'막힐 때까지 미끄러진다'는 핵심 규칙이 사실상 '어디서든 멈춘다'가 되어, 별 3개(최소 이동)는 어려워도 탈출(진행)은 생각 없이 가능했다.

## 새 규칙

- 빈 물 칸을 누르면 그물을 친다. **친 그물은 걷을 수 없다.** 되돌리기와 처음부터로만 무를 수 있다.
- 남은 그물은 어느 이동 전이든 더 칠 수 있다. 그물 치기는 이동 횟수에 포함되지 않는다.
- 친 그물을 누르면 "한 번 친 그물은 걷을 수 없어요. 되돌리기로 무를 수 있어요."를 보여 준다. 그물을 다 쓴 뒤 빈 칸을 누르면 되돌리기를 안내한다.
- 그물을 잘못 쳐서 숭어를 다 먹을 수 없으면 힌트가 탈출 길과 "숭어를 모두 먹으려면 되돌리기가 필요해요"를, 나갈 길도 없으면 되돌리기를 안내한다.

## 코드

- `engine.js`
  - `placedPlanSearch()`: 친 그물을 탐색 상태에 넣는 새 풀이기. 이번 이동의 경로나 구조정 옆 칸에만 새 그물을 시도한다. 다른 칸은 그 칸이 영향을 주는 이동 직전에 쳐도 결과가 같아서 미뤄도 최적성이 유지된다.
  - `planSearch()`·`plan()`의 기본값이 새 규칙이다. 마지막 인자 `pickup = true`는 이전 규칙이다.
  - 전수 탐색과 비교해 검증했다: 무작위 수문 판, 무작위 구조정·숭어 판, 스토리 그물 수로 18개.
- `game.js`
  - `netPickup()`: 스토리와 일일 v4·자유 v4는 `false`.
  - 이전 규칙으로 만들고 별 기준을 정한 일일 작전 v1–v3, 이전 단일 일일, 자유 수로 v1–v3 판은 `true`라서, 그 판에서는 계속 걷을 수 있다.
  - 힌트·첫 그물 안내도 같은 규칙으로 찾는다.
- `daily.js`·`free.js`
  - 일일 작전 v4, 자유 수로 v4: 그물 유형을 새 규칙으로 만들고 평가한다.
  - 예비 수로는 이전 규칙 기준이라 그물 예비 수로는 쓰지 않고, 다른 유형으로 생성한다.
  - 그물이 없는 판은 두 규칙의 결과가 같으므로 v3과 같다.
  - 1년(2026-10-08부터) 검사 결과: 예비 수로 사용 0, 실패 0, 가장 오래 걸린 준비 163ms(Node).
- `tools/replay-plan.js`: 해법 재생에서 그물이 사라지면 실패한다. `pickup: true`는 이전 규칙의 해법용이다.
