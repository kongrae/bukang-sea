## 홍보 영상 (유튜브 쇼츠·인스타그램 릴스)

`node tools/promo-video.js` → `outputs/promo/shark-sos-short.mp4`

- 영상 파일은 저장소에 올리지 않는다. 같은 명령으로 다시 만든다. Edge나 Chrome이 필요하고, 자막 글꼴을 Google Fonts에서 받으므로 인터넷도 필요하다.
- 1080×1920 세로 영상이다. 길이는 약 24.6초이고 H.264·AAC MP4에 게임 효과음이 들어 있다.
- 녹화기가 만든 조각 MP4를 `tools/mp4-progressive.js`로 다시 묶었다. 그래서 일반 MP4가 되어 윈도우와 휴대폰 갤러리도 길이를 읽는다.
- 화면은 손으로 조작한 장면이 아니다. 출시 규칙과 풀이기 해법으로 정식 수로 4개를 자동 플레이했다.
- 함께 나오는 파일:
  - `contact-sheet.png`: 1.5초 간격 장면 모음
  - `frame-*.png`: 주요 장면
  - `report.json`: 길이, 소리 크기, 장면 시각

| 0–4초 | 4번 수로 '첫 물살의 방향' | 수로에 갇힌 상어, 바다로 보내 줄래요? → 밀면 벽까지 쭉! 물살을 타면 꺾여요 |

- '광고 없음'은 영상에 넣지 않고 글에만 적었다. 나중에 광고를 넣으면 이미 퍼진 영상은 고칠 수 없기 때문이다.
- 올릴 때는 쇼츠나 릴스 편집기에서 밝은 음악을 깔고, 원본 소리를 조금 줄여 섞으면 좋다. 표지로는 첫 장면(`outputs/promo/frame-1.png`)이 무난하다.
- 쇼츠 설명란의 링크는 눌리지 않는다. 그래서 "구글 플레이에서 '상어 SOS' 검색"을 함께 적는다. 2026-10-23 Play 웹 검색에서 이 검색어로 1위인 것을 확인했다.

## 문제형 쇼츠 (2026-10-27)

수로 하나를 문제로 내고 5초 뒤에 정답을 보여 주는 영상 10개다. 영상 하나로는 반응을 판단할 수 없어서, 매번 다른 수로로 올려 본다.

`node tools/promo-video.js --quiz` → `outputs/promo/quiz/`

- `quiz-NN-canal-C.mp4`: 1080×1920 영상. 길이는 이동 수에 따라 약 15~17초이고 게임 효과음이 들어 있다.
- `quiz-NN-cover.png`: 0.6초 장면(문제와 타이머 5)이다. 쇼츠 표지로 쓴다.
- `quiz-NN-sheet.png`: 1.5초 간격 장면 모음이다. 검수용이다.
- `posts.txt`: 영상별 제목·설명·해시태그다.
- `report.json`: 길이, 소리 크기, 이동 수, 정답 순서다.
- 일부만 다시 찍으려면 수로 번호를 적는다. 예: `node tools/promo-video.js --quiz=13,62`. 파일 번호 NN은 바뀌지 않는다.

| 시간 | 화면 |
|---|---|
| 0~5초 | 문제("숭어 2마리 다 먹고 / 7번 만에 나갈 수 있을까요?"), 5초 타이머, 규칙 두 줄(밀면 벽까지 쭉 + 그 수로의 장치) |
| 5초~정답 끝 | "정답 공개!" 뒤에 해법을 재생한다. 위쪽 칸에 이동 방향이 하나씩 채워진다 |
| 그다음 2.3초 | 별 3개 결과창과 "몇 번 만에 풀었나요?" |
| 마지막 3.4초 | 엔딩 카드와 "구글 플레이에서 '상어 SOS' 검색" |

- 정답은 출시 규칙으로 풀이기 해법을 재생한 것이다. 이동 수는 숭어를 모두 먹는 최소 이동이고, 그물 치기는 이동 수에 넣지 않는다.
- 쇼츠·릴스는 화면 아래쪽이 제목과 버튼에 가려진다. 그래서 문제·타이머·정답 칸을 모두 위쪽 띠에 둔다. 게임 화면을 띠만큼 아래로 내려서 판은 가리지 않는다. `report.json`의 `clearance`가 띠와 판 사이 여백(px)이다.
- 올릴 순서는 7(기본) → 8(물살) → 74(상자) → 42(그물) → 71(소용돌이) → 13(구조정) → 62(수문) → 37(모래톱) → 31(그물·숭어 3마리) → 83(물살·상자)번 수로다.

올리는 방법:

- 하루에 한 개씩 올린다. 같은 영상을 유튜브 쇼츠·인스타그램 릴스·틱톡에 함께 올린다.
- 2주 뒤 영상별 조회 수와 Console의 '광고 및 추천' 방문자 수를 날짜별로 비교한다. 2026-10-27 확인 결과 Play Console 통계에는 UTM 항목이 없다. 그래서 출처는 올린 날짜로 구분한다.
- 쇼츠 설명란의 링크는 눌리지 않는다. 그래서 영상과 설명 모두 "구글 플레이에서 '상어 SOS' 검색"으로 안내한다. 눌리는 링크는 채널·프로필에만 둔다.
- 정답을 맞힌 댓글에는 답글을 단다. 다른 해법을 찾은 댓글은 다음 문제 소재로 쓴다.
- 유튜브 스튜디오에서 설명 끝 해시태그를 친 채 다른 곳을 누르면 자동완성 목록이 선택될 수 있다. 실제로 `#shorts`가 `#shortsfunny`로 바뀐 적이 있다. 해시태그 뒤에 공백을 넣고, 게시 직전에 설명을 다시 확인한다.

- 게시판마다 자작 게임 홍보가 허용되는지, 말머리 규칙이 있는지 먼저 본다. 같은 글을 여러 곳에 한꺼번에 올리지 않는다.
