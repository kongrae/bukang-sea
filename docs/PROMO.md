# 홍보 영상과 소개글 (2026-10-23)

프로덕션 출시(2026-10-22) 뒤 설치 유입이 없어서 무료 홍보용으로 만든 자료다. 앱 이름과 숫자는 `STORE.md`에 맞춘다. 상표 분쟁이 있는 "부캉이"라는 이름은 쓰지 않는다.

## 홍보 영상 (유튜브 쇼츠·인스타그램 릴스)

`node tools/promo-video.js` → `outputs/promo/shark-sos-short.mp4`

- 영상 파일은 저장소에 올리지 않는다. 같은 명령으로 다시 만든다. Edge나 Chrome이 필요하고, 자막 글꼴을 Google Fonts에서 받으므로 인터넷도 필요하다.
- 1080×1920 세로 영상이다. 길이는 약 24.6초이고 H.264·AAC MP4에 게임 효과음이 들어 있다.
- 녹화기가 만든 조각 MP4를 `tools/mp4-progressive.js`로 다시 묶었다. 그래서 일반 MP4가 되어 윈도우와 휴대폰 갤러리도 길이를 읽는다.
- 화면은 손으로 조작한 장면이 아니다. 출시 규칙과 풀이기 해법으로 정식 수로 4개를 자동 플레이했다.
- 함께 나오는 파일:
  - `contact-sheet.png`: 1.5초 간격 장면 모음
  - `frame-*.png`: 주요 장면
  - `report.json`: 길이, 소리 크기, 장면 시각

| 시간(약) | 장면 | 자막 |
|---|---|---|
| 0–4초 | 4번 수로 '첫 물살의 방향' | 수로에 갇힌 상어, 바다로 보내 줄래요? → 밀면 벽까지 쭉! 물살을 타면 꺾여요 |
| 4–8.5초 | 25번 '첫 그물 자리' | 톡! 그물을 치면 그 앞에서 멈춰요 |
| 8.5–13초 | 49번 '첫 소용돌이 건너기' | 소용돌이에 들어가면 건너편으로 슝! |
| 13–21초 | 63번 '되돌아올 때의 수문'과 별 3개 결과창 | 스위치를 밟으면 수문이 열리고 닫혀요 → 숭어까지 다 먹고 나가면 별 3개! |
| 21–24.6초 | 엔딩 카드(메인 화면 바다와 앱 아이콘) | 상어 SOS · 바다로 보내줘! · 84개 수로 · 매일 새 구조작전 · 오프라인 플레이 · Google Play에서 무료 |

- '광고 없음'은 영상에 넣지 않고 글에만 적었다. 나중에 광고를 넣으면 이미 퍼진 영상은 고칠 수 없기 때문이다.
- 올릴 때는 쇼츠나 릴스 편집기에서 밝은 음악을 깔고, 원본 소리를 조금 줄여 섞으면 좋다. 표지로는 첫 장면(`outputs/promo/frame-1.png`)이 무난하다.
- 쇼츠 설명란의 링크는 눌리지 않는다. 그래서 "구글 플레이에서 '상어 SOS' 검색"을 함께 적는다. 2026-10-23 Play 웹 검색에서 이 검색어로 1위인 것을 확인했다.
