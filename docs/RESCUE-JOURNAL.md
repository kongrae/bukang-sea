# 구조일지와 누적 보상

콘텐츠 개선 2번. 오늘의 구조작전 참여를 달력에 남기고, 쉬어 가도 유지되는 누적 목표를 제공한다. 메인 화면 ‘구조일지’ 또는 작전 선택 화면 ‘구조일지 · 누적 보상’에서 연다.

## 기록과 기념품

한 수로 이상 완료한 날짜는 참여 도장(●), 세 수로 모두 완료한 날짜는 구출 성공 도장(✓)이다. 별 개수에 관계없이 탈출하면 인정하며, 같은 날짜 재도전은 횟수를 늘리지 않는다. 작전 완료일은 참여일에도 포함된다. 상단에는 다음 기념품까지 남은 일수를, 아래에는 모든 보상 조건과 진행 상황을 표시한다. 기록이 있는 첫 달부터 현재 달까지 이동할 수 있다.

| 조건 | 자동 보상 |
|---|---|
| 누적 참여 1일 | 첫 물길 기념 배지 |
| 세 수로 완료 1일 | 구출 성공 기념 배지 |
| 누적 참여 3일 | 산호 상어 외형 |
| 세 수로 완료 7일 | 별바다 상어 외형 |
| 누적 참여 30일 | 든든한 동행 기념 배지 |
| 세 수로 완료 30일 | 베테랑 구조대 기념 배지 |

획득은 자동이며 별도 수령 버튼이나 비용은 없다. 새 배지·외형은 클리어 결과에도 표시한다. 외형은 ‘내 상어’에서 선택하며 기존 7개 상어의 조건과 소유권은 유지한다. 스토리 별·일일 별·연속 일수의 기존 규칙은 바꾸지 않는다.

## 저장과 이관

기존 `bukang-sea-v1` 저장 키 안에 `journal: { version: 1, days: { 날짜: 1 또는 2 } }`를 추가한다. 1은 참여, 2는 세 수로 완료이며 같은 날짜의 도장은 높이기만 한다. 구조일지 날짜는 삭제하지 않는다. 별·퍼즐 진행용 `daily`와 `dailyOps`의 최근 120일 제한은 그대로 유지한다. 누적 수치는 도장의 개수로 계산하므로 재접속·재도전·기록 정리로 중복되거나 줄어들지 않는다. 기기에만 저장되며 브라우저 데이터 삭제 또는 다른 기기로 이동하면 공유되지 않는다.

첫 실행 때 남아 있는 유효한 `daily` 참여 기록과 현재 버전 `dailyOps`의 단계별 별을 합친다. 기존 단일 수로의 별 3개는 참여만 인정하며 새 작전 완료로 바꾸지 않는다. 이미 정리되어 사라진 과거 날짜는 복원하거나 추정하지 않는다. 잘못된 날짜·도장·별·미지원 작전 버전은 이관하지 않는다. 자정 이후 완료한 판은 시작한 퍼즐의 날짜에 기록한다. 기존 별·선택 외형·소유 외형·설정·진행 중 수로는 유지한다.

## 검증

`npm test` 47개와 `npm run verify`의 스토리 48개가 통과했다. 구조일지 검사는 기록 이관·중복 제거·비연속 140일 기록/120일 정리 후 유지·오래된 날짜 재도전·늦게 완료된 날짜·보상 조건·보유 외형 유지·윤년 달력·빈 기록·작전 화면 복귀를 포함한다. 기존 일일 v1과 이전 v2의 90일 맵·별 기준 해시도 유지했다.

브라우저에서는 실제 기존 참여 1일/작전 완료 1일의 이관, 달력과 획득 배지/남은 보상 표시, 320×568·360×640 레이아웃, 닫기·Escape·작전 복귀·상어 선택 이동을 확인했다. 3일/7일 보상 조건과 누적 기록은 자동 검사하며, 보상 외형의 획득·선택 렌더링은 격리된 합성 기록 화면에서 점검한다. 합성 기록은 공개 배포와 스토어 화면에 포함하지 않는다. 실물 휴대폰 터치·실제 이용자의 재방문 개선은 별도 검증이 필요하다.

실제 자정이 지난 2026-10-01에도 참여/완료 1일이 유지되고, 이전 달로 이동해 9월 30일 완료 도장을 조회한 뒤 현재 달로 복귀했다. 격리된 합성 7일 기록에서는 산호·별바다 상어가 자동으로 열리고, 두 외형을 선택한 뒤 새로고침해 별바다 상어 선택 유지까지 확인했다.
