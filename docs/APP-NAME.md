# 상어 SOS: 바다로 보내줘!

2026-09-30 사용자 선택으로 앱 이름을 확정했다. 부산 북항 수로에 갇힌 상어를 구해 바다로 보내는 설정을 담는다.

- 전체 이름: **상어 SOS: 바다로 보내줘!**
- 메인 제목/홈 화면 이름: **상어 SOS**
- 부제: **바다로 보내줘!**

웹 문서 제목, PWA manifest 이름과 short_name, Apple 홈 화면 메타데이터, Capacitor appName과 Android 표시 이름, 개인정보처리방침, 스토어 등록 문구와 홍보 그래픽에 반영했다. 메인 배너의 산책로와 전체 높이를 각각 16px 늘려 제목/부제를 배치하고, 물 영역과 상어 크기는 유지했다.

저장 키 `bukang-sea-v1`, 앱 ID `kr.hongrae.lostshark`, 저장소 이름과 Pages 주소는 유지한다. 이름 변경으로 기존 별·스킨·이어하기·힌트 사용 기록을 초기화하지 않는다.

## 확인

- 360×640과 390×844에서 메인 제목/부제가 잘리지 않으며, 360px의 제목은 36px로 표시되고 가로 넘침이 없다.
- 기존 별 36개·기본 스킨·2종 보유·오늘의 수로 완료 상태를 확인했다. 수로 13의 0회 이어하기 진입/목록 복귀를 확인했다.
- 1024×500의 홍보 그래픽과 360×640의 제목/챕터 화면을 새 이름으로 저장했다. 현재 스토어 이미지 경로는 `STORE.md` 참고.
- 내장 폰트를 재생성하고 `build`, `build:artifact`, `build:web`, `build:playtest`, `cap:sync`를 확인했다. Android에 최신 웹 자산과 새 표시 이름을 반영했으며, 설치된 앱의 기기 동작이나 Play Store 업로드를 검증한 것은 아니다.
- `npm test` 36개와 `npm run verify` 48개 수로 통과.

이름 변경의 브라우저 확인은 실제 이용자의 반응이나 실물 기기의 설치 시험을 대신하지 않는다.
