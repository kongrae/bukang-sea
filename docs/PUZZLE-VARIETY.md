## 반복의 원인

48개 스토리는 모두 다른 배치지만, 회전·반사를 합친 벽 모양은 18종이었다. 자유 쉬움 90시드도 배치 자체는 90개였지만 벽 모양은 3종, 한 최단 해법의 방향 문자열은 24종에 그쳤다. 같은 좁은 이동 수 범위에 물체를 다시 배치하는 방식이어서, 새 판이 나와도 익숙한 정지점과 수집 경로를 되풀이하기 쉬웠다.

장치가 있다는 사실도 활용을 뜻하지 않았다. 기존 43번은 소용돌이가 있었지만 검사한 최단 수집 경로에서는 사용하지 않았다. 따라서 이번에는 공간 구조와 장치 활용 조건을 함께 바꿨다. 스위치·수문은 다음 실험으로 남겼으며 엔진의 이동 규칙과 조작은 유지했다.

모든 생성 판은 실제 무료 그물 재배치/구조정 규칙으로 해법, 이동 범위, 탈출보다 긴 숭어 수집 경로를 검증한다. 장치 유형은 선택된 해법에서 주 장치를 사용해야 한다. 그물 유형은 그물 없는 해법이 없고 배치가 두 번 이상 바뀌어야 한다. 탐색 한도 초과를 해법 없음으로 취급하지 않는다. 사전 검증한 예비 맵은 59개이며, 유형과 이동 범위에 맞는 후보 중 시드로 선택한다. 모든 예비 맵을 재생하고 생성 실패도 강제로 시험한다.

자유 수로 v2는 쉬움 4–8 / 보통 6–11 / 도전 8–14 최단 이동을 허용한다. 탈출 하한은 2/3/4, 별 여유는 2/1/0이다. 범위를 겹쳐 같은 길이에 다른 공간과 장치를 경험하도록 했다. 자유 수로의 최근 6개 배치는 저장 후에도 회피한다. 정적인 판은 방향을 보정한 회전·반사도 비교하며, 구조정이 있는 판은 초기 진행 방향이 달라질 수 있어 정확한 배치로 비교한다. 최대 12시드를 시도하고 앞 8시드는 직전 유형·마스크도 피한다. 실패·취소하면 기존 판과 힌트를 보존한다. 생성기 자체는 이력을 받지 않으므로 동일 시드·난이도·버전은 같은 판이다.

일일 v2는 7개 주제로 세 판을 연결한다.

| 주제 | 1 → 2 → 3단계 |
|---|---|
| 돌아오는 물길 | 갈림길 탐색 → 돌아오는 길 → 옮겨 쓰는 그물 |
| 멈춤의 기술 | 작은 우회 → 멈추고 방향 바꾸기 → 옮겨 쓰는 그물 |
| 흐름 따라 탐험 | 돌아오는 길 → 물살의 방향 → 떨어진 물길 |
| 구조정과 한 바퀴 | 갈림길 탐색 → 움직이는 정지점 → 움직이는 정지점 |
| 섬 너머 구출 | 돌아오는 길 → 멈추고 방향 바꾸기 → 떨어진 물길 |
| 갈림길 작전 | 작은 우회 → 물살의 방향 → 옮겨 쓰는 그물 |
| 다시 만나는 길 | 갈림길 탐색 → 움직이는 정지점 → 떨어진 물길 |

일일의 5–7 / 8–10 / 11–14 이동 범위는 유지한다. 같은 날짜·단계·버전은 같은 판이고 사용자의 플레이 이력은 생성에 영향을 주지 않는다. 이전 버전으로 그날의 작전을 시작한 사용자는 세 판 모두 이전 버전으로 이어간다.

## 저장 호환과 검증 경계

- 스토리 진행 중인 교체 수로는 저장된 맵 서명이 일치할 때 배포에 포함한 이전 정의로 복원한다. 재시작도 같은 이전 판을 유지하고, 완료 후 새로 선택할 때 개선판을 제공한다. 임의 저장 맵을 실행하지 않는다.
- 이전 자유 v1과 일일 작전 v1 생성기를 동결해 둔다. 이전 단일 일일 v2도 유지한다. 저장 키·수로 인덱스·최고 별·스킨·힌트·되돌리기 계약을 보존한다. 자유의 새 판만 v2로 전환한다.
- 자동 테스트 105개 통과. 자유 개선판 900시드, 일일 개선판 90일×3단계, 이전 자유 270배치/일일 270배치 지문, 이전 단일 일일 90일 지문, 예비 59개 해법, 교체 스토리 12개 복원·재시작, 최근 6개 회피·취소·실패를 포함한다. 새 v2의 맵·별 기준도 지문으로 고정했다.
- `npm run verify`: 스토리 48개 실제 해법·그물 필요성·별 기준 통과. Android 디버그 APK 빌드 통과.
