# 도전 수로 v5 · 상어 물결 정리

2026-10-14. 비교 기준 `c1b5fba`. 적용 범위는 **새 자유 수로의 도전 난이도, 새 일일 작전의 세 번째 도전**이다. 정식 84개 스토리 수로와 쉬움·보통 구성은 유지한다.

## 변경 이유와 구현

- 상어 아래 흰 타원은 `drawObliqueShark()`의 상시 장식이었다. 9개 스킨 공통으로 외곽선을 없애고 접촉 그림자의 크기·불투명도를 줄였다. 헤엄칠 때 생겼다 사라지는 기존 wake 처리와 루프를 사용한다.
- 기존 도전은 다른 난이도와 비슷한 작은 공간을 재활용했다. v5 도전은 10×14·11×13의 8개 전용 벽 구조(다중 방, 연결 통로, 순환로, 포켓, 분리 수역)를 사용한다. 숭어 4마리가 가로·세로에 퍼지고, 전부 수집 최단 경로 14–22회, 탈출만 하는 경로 6회 이상, 둘의 차이 4회 이상이어야 채택된다. 기존 학습 조건을 따르며 주 장치를 실제 해법에 써야 한다. 그물은 기존 고정 규칙대로 최대 1개다.
- 글자 확대 시 큰 맵의 최소 타일 24px를 확보하고 게임 화면을 스크롤한다. 일반 세로 화면은 화면에 맞춘다. 그물 칸의 정밀 터치는 작은 실제 기기에서 추가 사용성 확인이 필요하다.

## 저장 호환과 적용 시점

자유·일일 생성기는 v5로 올렸고 v1–v4의 마스크·목표·시드·별 기준은 유지한다. 자유 수로는 **도전 → 새 수로**에서 커지고 이어하기는 원래 판을 복원한다. 이미 시작한 오늘의 일일 작전은 세 수로 모두 이전 버전을 끝까지 사용한다. 다음 새 날짜의 작전부터 커진다. 아직 시작하지 않은 오늘의 작전은 v5다.

`dailyLearned(date, version)`은 이전 일일 버전의 저장된 학습 목록도 복원한다. 학습 목록이 없던 이전 버전은 종전 전체 장치를 사용한다. 기존 세션·별·힌트·소유 스킨을 일괄 변환하지 않는다. Pages 개발 빌드의 전체 해금·별도 저장 키와 출시 빌드의 정상 해금 정책도 유지한다.

## 확인 결과

- `npm test`: 249개 통과. v4 자유 360개 + 일일 189개의 변경 전 전체 결과 지문 일치. v5 360개 표본의 크기·숭어·실제 해법·우회·장치·학습 제한·결정성 검사. 실제 게임 핸들러의 v4 자유/일일 복원 및 새 판만 v5로 교체되는 동작 확인.
- `node tools/challenge-audit.js`: 신규 자유 도전 300시드 + 일일 도전 90날짜, 생성 실패 0, 표본 내 배치 중복 0. 자유 최단 v4 8–14회 → v5 14–22회, 일일 v4 11–14회 → v5 14–22회. v5 표본 모두 4마리, 140/143칸. 벽 구조는 기존보다 적은 전용 8개이며 장치·수집 배치가 달라진다. 구조의 수와 체감 난이도는 별개다.
- Node 생성 시간(중앙값/95백분위/최대): 자유 6.49/135.57/405.58ms, 일일 15.06/151.68/434.75ms. 브라우저는 기존 약 8ms 작업 분할을 유지한다. 저사양 실제 기기는 미측정.
- `npm run verify`: 정식 84개와 이전 시험 12개 통과. 단일 HTML·artifact·웹·개발 APK·출시 AAB 빌드와 출시 자산 검사 통과. Play Console 업로드 없음.
- `tools/challenge-qa.js`: 실제 렌더러에서 그물/물줄기/소용돌이 3맵 × 입체/탑뷰 완주, 좌표로 그물 설치, 되돌리기·복원·4마리 클리어. 320×568, 360×640, 390×844, 412×915, 844×390과 계산된 글자 크기 200% 확대 확인. 9개 스킨의 원 제거, 이동 wake 생성·소멸, 로드 후 오프라인 이동 확인. 브라우저 오류 0.

화면 증거는 Headless Edge 모바일 에뮬레이션이다. 실제 Android 기기·물리적 터치·OS 글자 확대·사람의 체감 난이도/재미 평가는 하지 않았다.
