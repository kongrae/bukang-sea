# 화면 가독성과 구조정 이동 연출 개선

2026-09-30 개선 작업 3번. 작은 화면에서 방향 장치·상어·이동 순서를 더 쉽게 구분하는 것이 목표다.

## 원인과 변경

- 물줄기의 반투명 청록색과 움직이는 꺾쇠가 물결과 비슷해 방향이 흐려졌다. 어두운 바탕과 밝은 테두리를 넣고, 중앙에는 움직이거나 흐려지지 않는 밝은 화살표를 표시한다. 물줄기 흐름은 화살표 뒤에 약하게 남긴다.
- 기본 상어가 물과 대비가 낮았다. 몸·지느러미를 밝게 조정하고 모든 스킨의 몸·꼬리·가슴지느러미에 밝은 윤곽을 넣는다. 스킨 무늬와 장식은 유지한다.
- 물 위 빛과 산책로 구경꾼이 퍼즐 장치와 시선을 경쟁했다. 물결의 밝기를 낮추고 구경꾼의 밀도·불투명도를 줄이며 수로 가장자리에서 더 떨어뜨린다. 산책로와 난간은 유지한다.
- 낮은 화면에서 HUD가 판 공간을 많이 차지했다. 높이 700px 이하에서는 제목·간격·칩 여백을 줄인다. 목록·설정 버튼은 44px, 하단 조작 버튼은 최소 높이 48px를 유지한다.
- 힌트 줄바꿈으로 판 높이가 바뀌어도 캔버스와 탭 좌표가 이전 크기에 남을 수 있었다. `ResizeObserver`로 실제 판 크기 변화를 감지해 다시 맞춘다.
- 규칙상 상어가 도착한 뒤 움직이는 구조정이 화면에서는 상어와 동시에 움직였다. 상어의 이동이 끝난 뒤 구조정을 0.16초 동안 이동·방향 전환하고 다음 입력을 실행한다. 모션 감소 설정에서는 상어 도착 시 구조정 위치를 즉시 갱신한다.

구조정 연출이 있는 턴은 최대 0.16초 길어진다. 실제 이동 규칙·맵·별 기준·저장 키·스킨 해금 조건은 바꾸지 않는다. 움직이지 못한 입력이나 탈출에는 추가 구조정 턴이 없다.

## 화면 측정과 검증

| 항목 | 이전 | 이후 |
| --- | --- | --- |
| 360×640, 12번 수로, 기본 안내의 칸 크기 | 39px | 41px |
| 390×844, 12번 수로의 칸 크기 | 55px | 55px |
| 기본 상어 몸 / 물의 단색 대비 | 약 1.55:1 | 약 2.80:1 |

새 상어 윤곽 / 물의 단색 대비는 약 4.72:1, 물줄기 화살표 / 어두운 바탕은 약 11.70:1이다. 대비 수치는 CSS 색의 상대 휘도로 계산한 값이며 실제 화면 픽셀 측정이나 접근성 인증 결과가 아니다. 360×640의 한 줄 힌트에서는 칸이 43px로 커지고 캔버스·탭 좌표가 함께 갱신되는 것을 확인했다. 모든 수로의 칸 크기가 44px 이상이라는 보장은 없다.

- `npm test`: 기존 풀이기·별 판정·대표 수로·일일 퍼즐 회귀 검사 11개와 구조정 연출 회귀 검사 4개, 총 15개 통과.
- 구조정 검사: 상어 이동 중 정지 → 도착 후 이동, 다음 입력 대기, 두 턴 되돌리기, 모션 감소, 막힌 입력·탈출의 턴 수 유지. 실제 `game.js` 함수를 실행하고 구조정 그리기 좌표를 기록한다. 캔버스 픽셀이나 실제 기기 입력을 검사하는 테스트는 아니다.
- `npm run verify`: 전체 48개 수로의 해법·그물 필요성·역할별 별 기준 검증 통과.
- `npm run build`, `npm run build:artifact`, `npm run build:web`: 배포 형식별 빌드 통과. 단일 파일 결과물과 현재 소스가 일치하며 내장 폰트의 글자 누락도 없다.
- 실제 브라우저: 360×640에서 12번 수로를 그물 설치·회수와 방향키 입력으로 숭어 3개, 9회 이동, 별 3개로 클리어했다. 힌트로 판 높이가 달라진 뒤에도 올바른 칸에 그물이 설치됐다. 390×844에서 판 배치와 스킨 미리보기도 확인했다. 기존 별 36개와 보유 스킨 2개는 유지됐다.

물리 휴대폰의 터치·Safari·네이티브 앱 검증과 초보 이용자의 가독성 평가는 아직 수행하지 않았다. 이번 작업에서는 공개 배포하지 않았다.
