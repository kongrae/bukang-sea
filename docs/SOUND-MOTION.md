## 2. 설계 원칙

1. **2층 구조:** 물리 층(실제 녹음: 물, 고무, 나무, 모래, 천·로프)과 음 층(실제 악기 단음: 마림바·실로폰·벨)으로 나눈다. 실패와 UI 소리는 물리 층만 쓴다. (Monument Valley 3, Peggle Blast)
2. **한 음계:** 모든 음 층을 A 장조 5음계(A·B·C#·E·F#)로 통일한다. (Peggle Blast)
   - 숭어 연속: A4 → B4 → C#5 → E5 → F#5 → A5
   - 마지막 숭어: 벨 층 A5 추가
   - 별 3개: 기존 A4–C#5–E5 유지
   - 현재 숭어 음(A4–C5–D5–E5)의 C·D는 별의 C#과 어긋나므로 이번에 맞춘다.
3. **변형 순환:**
   - 변형 수: 자주 나는 소리 3개, 중간 2개, 드문 보상 1개
   - 같은 변형을 연속으로 쓰지 않는다.
   - 물리 층 피치 변주는 ±2% 이내, 음 층은 음정을 유지한다. (Monument Valley 3)
4. **움직임 연결:** 소용돌이는 진입·재등장 구간에 맞춰 물리 층의 재생 속도를 내렸다 올린다. 물줄기는 실제 통과 시점에 낸다. (Monument Valley 3)
5. **절제:**
   - 동시 재생 상한·간격 제한·획득 우선 규칙을 유지한다. (Mini Metro)
   - 화면 흔들림·진동·입력 지연은 없다.
   - 효과는 이벤트당 하나의 뚜렷한 반응으로 둔다. (Don't Juice It or Lose It)
6. **실패는 부드럽게:** 막힘은 짧고 낮은 물리음만 쓴다. 벌을 주는 느낌을 내지 않는다(게임 톤 '바다로 돌려보내기').
7. **AI 아님 근거:** 2022년 이전에 공개됐고 AI 표시가 없는 사람 제작·녹음 음원을 우선한다. 출처마다 공개 연도와 녹음 설명을 기록한다.

## 5. 기술 기본안 (FX04 준비)

- **형식:** 재인코딩 없이 원본(Kenney OGG, Freesound MP3)을 그대로 내장한다. 자르기·페이드·음량은 Web Audio 재생 시 시작 위치·길이·게인으로 처리한다. ffmpeg가 필요 없다.
- **디코드 실패:** Safari처럼 OGG 디코드가 실패하는 환경에서는 해당 소리만 기존 합성음으로 대체한다. 주 대상인 Android 앱(WebView)·Chromium은 OGG와 MP3를 모두 디코드한다(FX04에서 실제 확인).
- **용량:** 이벤트 21개 × 평균 2변형 × 약 8KB ≈ 340KB(base64 약 450KB)로 추정한다. 400KB를 넘으면 변형 수를 줄이고, 그래도 크면 ffmpeg 재인코딩을 사용자에게 제안한다.
- **디코드 시점:** 첫 사용자 입력 뒤에 한 번에 디코드하고 캐시한다(Monument Valley 3의 시작 시 일괄 로드와 같은 방식).
- **출처 기록:** `assets/audio/LICENSES.md`에 파일별 출처, 작성자, 라이선스, 공개 날짜, AI 아님 근거, 가공 내용을 남긴다.
