# 자유 수로

콘텐츠 개선 4번. 메인의 오늘의 구조작전 아래에서 원하는 난이도를 골라 계속 새 퍼즐을 즐긴다. 날짜나 스토리 개방 단계와 관계없이 세 난이도를 모두 선택할 수 있다.

## 플레이와 기록

- 쉬움·보통·도전마다 진행 중인 판을 하나씩 보관한다. 이동·숭어·그물·구조정·되돌리기 기록까지 이어 하며 날짜가 바뀌어도 유지한다.
- 진행 중에는 **이어하기 / 새 수로**, 완료 후에는 **새 수로 / 다시 풀기**를 제공한다. 새 수로가 준비되면 해당 난이도의 이전 판을 교체한다. 생성 취소·실패·연속 동일 맵은 기존 진행을 지우지 않는다.
- 별 판정은 탈출 → 숭어 전부 → 숭어 전부와 이동 기준 충족 순서로 같다. 난이도별 누적 완료 횟수는 각 판의 첫 탈출에만 증가한다. 재도전은 최고 별만 갱신한다.
- 자유 수로 기록은 스토리 별, 일일 참여·연속 기록, 구조일지 보상과 별개다. 하루 제한은 없다.
- 힌트도 처음 두 회 즉시, 이후 12초 간격이다. 같은 판의 재시작·재도전·새로고침은 사용 기록을 유지하고, 새로운 판이 확정될 때만 새 두 회를 제공한다.
- 작은 화면에서는 선택 목록 안쪽을 스크롤하며 닫기 버튼은 위에 남는다.

## 생성과 저장

`src/free.js`의 `FREE_VERSION = 1`과 32비트 시드로 같은 퍼즐을 재현한다. 기존 마스크·배치 함수와 실제 그물 재배치 규칙의 `operationPlan()`을 재사용한다. 기존 날짜별 생성기·버전·레시피는 변경하지 않았다.

| 난이도 | 숭어 전부 수집 시 최소 이동 | 별 기준 여유 | 탈출만 할 때 최소 이동 |
|---|---:|---:|---:|
| 쉬움 | 5–7 | +2 | 3 이상 |
| 보통 | 8–10 | +1 | 4 이상 |
| 도전 | 11–14 | 없음 | 5 이상 |

모든 판은 숭어를 모으는 우회가 필요하며, 그물 판은 그물 없는 전부 수집 해법이 없어야 한다. 240개 후보의 한도 내에서 생성하고 조건을 만족하지 못하면 검증된 예비 맵을 사용한다. 브라우저에서는 약 8ms 단위로 작업을 나눠 실행한다. 직전과 같은 맵은 최대 다섯 시드까지 다시 시도하며, 모두 같으면 교체 없이 재시도 안내를 제공한다. 모든 과거 맵과의 중복을 보장하지는 않는다.

기존 저장 키 `bukang-sea-v1` 안에 다음 필드를 추가했다.

```js
free: {
  version: 1,
  runs: [ // 난이도별 최근 한 판. 빈 자리는 null 또는 미정의
    {version: 1, difficulty: 0, seed: 42, serial: 1, stars: 0, layout: '맵/그물 서명'}
  ],
  completed: [0, 0, 0]
}
sessions: { /* 기존 세션 유지 */, free0, free1, free2 }
hintUsage: { /* 기존 기록 유지 */, 'free:v1:난이도:회차:시드': {count, lastUsed} }
```

맵은 저장하지 않고 시드로 복원하며 서명을 대조한다. 이전 맵과 불일치하면 이어하기를 중단하고 새 수로로 복구할 수 있다. 저장 구조가 잘못된 자유 수로 필드만 초기화하며 기존 진행과 스킨은 유지한다. 새 판 확정 시 해당 난이도의 이전 힌트 기록과 생성 캐시를 정리한다. 생성 방식 변경은 자유 수로 버전과 기존 저장 호환을 함께 검토해야 한다.

## 검증 범위 — 2026-10-01

- `npm test`: 총 61개 통과. 자유 수로 900개(난이도별 시드 0–299)를 두 번 생성해 동일성·실제 해법 재생·난이도·별 기준·그물 필요성을 확인했다. 세 난이도의 저장 복원, 스토리/일일/구조일지 기록 격리, 완료 중복 방지, 최고 별 유지, 새 판의 힌트 초기화, 취소·실패·동일 맵 재시도, 잘못된 저장의 복구도 검사했다.
- 기존 90일 × 세 구조작전 및 이전 일일 v2의 90일 맵·별 기준 호환 검사 통과. `npm run verify`: 스토리 48개 해법 통과.
- 브라우저에서 무작위 쉬움 수로의 첫 힌트 → 두 이동 → 새로고침 → 이어하기 → 여섯 이동으로 별 세 개 완료를 확인했다. 실제 선택·키보드 입력이며 자동 해법 재생 결과와 구분한다.
- 같은 쉬움 수로를 다시 완료해도 누적 1개가 유지됐고, 결과의 새 수로 버튼은 2번째 판과 힌트 두 회로 연결됐다. 보통 한 이동과 도전 그물 설치를 따로 저장한 뒤 도전의 새로고침·이어하기·되돌리기로 그물 수가 0 → 1로 복원됨을 확인했다. 기존 스토리 12/48, 별 36개, 구조일지 참여 1일/완료 1일과 스킨 2/9 표시는 유지됐다.
- 320×568·360×640·390×844 화면에서 목록 스크롤, 고정 닫기, 44px 이상의 선택 버튼을 확인했다. 작은 화면에서는 세 난이도와 설명을 모두 보려면 목록을 내려야 한다.
- 웹/단일 파일/아티팩트 빌드와 Capacitor 웹 자산 동기화, 새 글자의 내장 폰트 반영을 수행했다.

실물 휴대폰의 터치 감도·생성 지연, 실제 이용자의 재미·재방문 효과는 아직 측정하지 않았다. 1–4번 구현 다음 단계는 `PLAYTEST.md`에 따른 이용자 시험이며 추가 기능 개발은 별도 요청을 기다린다.
