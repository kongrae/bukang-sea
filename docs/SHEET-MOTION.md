# 메뉴·시트·버튼 전환 — 애니메이션 7번

> 2026-10-03 후속: 드래그 닫기와 고정 헤더/닫기 버튼을 추가했다. 현재 동작과 검증은 [바텀시트·이동 개선](UI-AND-MOTION-IMPROVEMENTS.md)을 함께 참고한다. 아래는 7번 작업 당시 기록이다.

2026-10-01. 기존 메뉴는 열림 연출만 있고 닫을 때 즉시 사라졌다. 설정과 내 상어는 다른 시트와 달리 배경 입력 차단과 닫은 뒤 포커스 복귀가 없었다. 수로 카드의 입장 애니메이션이 끝난 뒤에도 transform을 유지해 눌림 반응을 덮을 수 있었다.

## 변경

- 공통 시트 처리를 여정·엔딩·오늘의 구조작전·자유 수로·구조일지·내 상어·설정·결과·장치 안내에 적용했다. 배경은 0.22초, 카드는 0.28초로 나타나며 아래 시트는 24px 이동, 넓은 화면 카드는 0.96배에서 시작한다. 닫힘은 0.16초이며 0.18초 뒤 입력을 복원한다.
- 닫힘 요청 시 논리적인 `hidden` 상태를 즉시 적용한다. 기존 생성 취소와 중복 요청 판정은 유지하고 CSS로만 짧은 퇴장 장면을 남긴다. 퇴장 중 시트와 배경 입력을 차단하며, 끝나면 원래 버튼으로 포커스를 돌린다. 새 시트나 화면으로 전환할 때 이전 퇴장 타이머를 정리해 뒤늦은 포커스 이동을 막는다.
- 열린 시트의 Tab/Shift+Tab은 활성화된 내부 컨트롤 사이에서 순환한다. 설정·내 상어·결과에도 모달 접근성 속성을 적용했다. 메뉴를 열면 진행 중 제스처와 대기 입력을 지우고 게임의 이동 연출 진행을 멈춘다. 메뉴를 닫으면 계속 진행한다.
- 일반 버튼은 80ms에 0.98배, 아이콘은 0.96배로 눌리며 180ms에 복귀한다. 주황 출발 버튼의 깊이 반응은 유지한다. 입장 애니메이션은 끝난 뒤 transform을 유지하지 않는다. 게임 진입/복귀는 각각 0.26/0.22초로 줄였다.
- 동작 줄이기에서는 퇴장 타이머 없이 닫는다. 문서 숨김·페이지 이탈·Capacitor 비활성화 시 남은 퇴장을 정리한다. 기존 게임 기록·보상·힌트 조건·생성 규칙은 유지하며 새로운 이미지나 라이브러리는 추가하지 않았다.

## 검증

- `npm test` 84개 및 `npm run verify` 전체 48개 수로 통과. 공통 시트의 실제 프로덕션 함수를 검사하는 네 테스트가 즉시 논리 종료, 퇴장 중 입력 차단, 중복 닫힘, 메뉴 교체, 포커스 복귀, 동작 줄이기/숨김 정리, Tab 순환을 확인한다. 기존 게임 로직 테스트는 즉시 표시하는 시트 어댑터를 사용한다.
- 390×844 브라우저에서 설정→장치 안내, 오늘의 구조작전→구조일지→복귀, 자유 수로 Escape 닫힘, 설정 Tab/Shift+Tab을 실제 조작했다. 메뉴가 열린 동안 방향키 입력으로 이동 수가 늘지 않았고 닫은 뒤 정상 이동했다.
- 일반 동작 QA에서 첫 수로를 실제 6회 이동으로 완료해 별 3개 결과를 확인했다. 다음 수로의 장치 안내를 닫고 메인으로 복귀했다. 열림 배경 0.22초/카드 0.28초, 닫은 뒤 포커스·입력 복원을 확인했다.
- 320×568에서 설정은 폭 320px, 높이 약 365px이며 컨트롤이 화면 안에 들어온다. 내 상어는 약 500px 높이의 스크롤 시트이며 Escape 뒤 `skinBtn`에 포커스가 복귀한다. 900×800에서는 약 520px 폭의 중앙 카드와 `pop` 입장 연출을 확인했다. 브라우저 오류 로그는 없었다.
- `build`, `build:artifact`, `build:playtest`, `cap:sync` 완료. Android 웹 자산을 동기화했으며 이번 작업에서 APK/AAB를 생성하지 않았다.

일반 동작을 강제하는 로컬 QA HTML은 `outputs/qa/sheet-motion.html`이며 동작 줄이기 판정만 우회한다. 실제 퇴장 시간·게임 기록·해금 조건은 바꾸지 않고 별도 테스트 기록을 사용했다. 캡처는 `outputs/qa/motion7-*.png`에 있다. 실물 휴대폰의 터치·성능·네이티브 뒤로가기 검증은 아직 수행하지 않았다. 전체 연출의 종합 점검은 8번에 남긴다.
