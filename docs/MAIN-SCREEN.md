# 디자인 개선 1 — 메인 화면 정리

2026-09-30. 큰 제목과 오늘의 수로/상어 선택 카드 때문에 작은 화면에서 스테이지 선택이 밀리는 문제를 개선했다.

## 화면 순서

1. 작은 제목 배너와 한 줄 조작 설명
2. 이어할 수로의 챕터/이름, 시작하기 또는 이어하기 버튼
3. 전체 별 합계, 챕터 선택 버튼 4개, 선택한 장의 수로 12개
4. 작은 오늘의 수로/내 상어 카드, 장치 범례

제목 배너는 기존 210~320px에서 128px(높이 700px 이하에서는 110px)로 줄였다. 제목 배너의 구경꾼은 좁아진 글자 영역과 겹치지 않도록 생략했다. 이어하기 버튼을 상단에 배치하면서 하단 고정 버튼의 스테이지 가림도 제거했다.

목록을 열거나 게임에서 돌아오면 유효한 스토리 세션의 장을 선택한다. 세션이 없으면 다음 미완료 수로의 장을 선택한다. 해당 수로를 주황 테두리로 표시한다. 다른 장을 둘러보는 동안에도 이어하기 버튼은 실제 진행 중 수로를 가리킨다. 잠긴 장은 목록을 볼 수 있지만 수로 버튼은 기존 조건에 따라 비활성화한다. 챕터 선택은 저장 기록을 변경하지 않는다.

## 검증

- 브라우저 360×640: 이어하기 버튼과 챕터 선택, 스테이지 첫 8개가 첫 화면에 보인다. 12개 목록은 세로 스크롤로 탐색한다.
- 브라우저 390×844: 해당 챕터의 12개 수로가 첫 화면에 보인다. 이어하기 버튼과 마지막 수로 사이에 겹침이 없다.
- 브라우저 1280×900: 앱 폭은 560px로 중앙 정렬하며 12개 수로와 오늘의 수로 카드를 볼 수 있다.
- 기존 별 36개/수로 13 진행 기록: 처음에 2장을 선택하며, 잠긴 3장을 둘러본 뒤 이어하기를 누르면 수로 13의 0회 상태로 들어간다.
- 별이 없는 신규 격리 테스트 기록: 1장 선택, 수로 1만 열림. 잠긴 4장 미리보기에서도 시작하기는 수로 1을 연다. 목록으로 복귀/새로고침 후 수로 1 세션을 이어할 수 있다.
- 하단 내 상어 시트와 오늘의 수로 진입, 첫 장치 안내/목록 복귀를 브라우저 입력으로 확인했다.
- `npm test`: 30개 통과. `npm run verify`: 48개 수로 통과.
- `build`, `build:artifact`, `build:web`: 통과. 추가된 글자를 포함해 내장 폰트를 재생성했다.

브라우저 크기별 확인은 실물 휴대폰 터치, 설치된 PWA/Android 앱, 이용자 관찰 결과를 대신하지 않는다.
