# 메인 화면 구성

2026-10-01. 사용자가 제시한 20대 미만 이용자 중심의 방향에 맞춰, 설명을 읽기 전에 할 일을 고를 수 있도록 재배치했다. 이전 메인은 날짜·진행 문구·챕터·12개 수로가 비슷한 비중으로 이어지고 내 상어·구조일지는 긴 목록 아래에 있었다.

## 첫 화면 순서

1. 움직이는 상어와 큰 게임 제목. 배너는 기본 184px, 높이 700px 이하에서는 168px이다. 지역 설명은 아래 게임 이야기에 남긴다.
2. 현재 수로와 진행 횟수, 큰 주황색 `구출 시작!` 또는 `이어서 구출!` 버튼, 한 줄 조작 설명. 버튼 글자는 28px, 높이는 64px이다. 긴 진행 문구를 버튼 위로 분리한다.
3. 노란 `오늘의 도전`과 민트색 `자유 수로`를 같은 크기의 두 카드로 나란히 배치한다. 각각 깃발·물결 아이콘, 짧은 설명, 진행/시작 표시를 사용한다. 오늘의 도전은 기존 오늘의 구조작전 시트로 연결된다.
4. 분홍색 `내 상어`와 밝은 `구조일지`를 같은 줄에 배치한다. 상어 미리보기, 수집 수, 도장 보상을 한눈에 확인한다.
5. `수로 골라 하기`를 누르면 구출 여정·챕터 선택·수로 목록을 펼친다. 아래 `게임 방법과 이야기`도 펼쳐보는 형식이다. 모든 수로 구출 뒤의 엔딩 다시 보기는 별도 버튼으로 유지한다.

모드 이름은 22–24px, 보조 정보는 12–14px로 구분한다. 색 외에도 아이콘과 이름을 함께 표시한다. 기존 공통 눌림·포커스·동작 줄이기 규칙을 사용하며 기본 HTML details/summary로 목록을 펼친다. 새 라이브러리나 이미지 자산은 추가하지 않았다.

## 진행과 보상 유지

- 큰 구출 버튼은 실제 스토리 세션이 있으면 해당 수로를 이어 한다. 다른 잠긴 장을 둘러봐도 이어할 대상이 바뀌지 않는다. 세션이 없으면 다음 미완료 수로, 모두 구출했다면 별 더 모으기로 연결된다.
- 메인으로 복귀할 때 목록을 접고 현재 진행을 표시한다. 구출 여정에서 장을 선택하면 목록을 펼친 뒤 해당 챕터 버튼으로 포커스를 이동한다.
- 목록을 접은 동안 새 별·다음 수로·챕터 해금 표시는 대기한다. 플레이어가 펼쳤을 때 한 번 연출하며 상단 별 합계는 즉시 갱신한다.
- 게임 규칙, 레벨 해금, 일일/자유 수로, 별·스킨·힌트·저장 형식은 유지한다. 추가 글자를 포함하도록 내장 폰트를 갱신했고 테스트 빌드 배지는 별도 상단 표시로 이동했다.

## 검증

- 자동 검사 92개와 전체 48개 수로 검증 통과. 접힌 목록의 보상이 열 때까지 보존되는 경우와 여정 선택 시 목록을 펼치는 경우를 기존 보상/여정 검사에 추가했다.
- 390×844에서는 구출 버튼 폭 366px/높이 64px, 두 모드 카드 각각 약 178×143px다. 내 상어·구조일지까지 약 604px 안에 들어온다.
- 320×568에서는 구출 버튼 폭 296px/높이 64px다. 두 모드 카드의 아래쪽은 약 479px 이내로, 세 가지 플레이 진입점이 첫 화면에 보인다. 수집/기록 카드의 아래쪽은 세로 스크롤로 접근한다.
- 신규 격리 기록에서 시작→1회 이동→메인 복귀 후 `이어서 구출!`과 `1회 진행`을 확인했다. 수로 목록은 접혀 있고 저장 내용은 유지된다.
- 목록 펼침, 잠긴 4장 둘러보기(해당 장 열린 수로 0개), 여정에서 챕터 선택과 포커스 복귀를 확인했다. 일일·자유·내 상어·구조일지 버튼은 각각 기존 시트를 열고 닫은 뒤 원래 버튼으로 포커스가 돌아왔다.
- 320/390/900px 폭에서 배치와 가로 넘침을 확인했고 브라우저 오류 로그는 없었다. 로컬 캡처는 `outputs/qa/home-layout-*.png`에 보관한다. 단일 HTML·아티팩트·테스트·웹 빌드와 Android 웹 자산을 갱신했다.

브라우저 조작은 실물 휴대폰의 터치 검증이나 해당 연령대 이용자 관찰을 대신하지 않는다. 실제 이용자에게 첫 화면에서 원하는 모드를 고르는 과정을 관찰하는 후속 시험은 `PLAYTEST.md`를 따른다.
