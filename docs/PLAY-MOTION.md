# 게임 중 움직임과 장치 반응 — 애니메이션 5번

2026-10-01. 기존 연출의 순서를 살펴보니 상어의 정지 반응이 구조정의 0.16초 이동까지 끝난 뒤 발생했다. 소용돌이 반응은 현재 프레임이 점프 구간 안에 있을 때만 실행돼 긴 경로나 낮은 프레임 빈도에서 생략될 수 있었다. 회수한 그물은 즉시 사라졌고, 숭어 잔상은 상어를 계속 따라가 소용돌이 또는 다음 이동까지 끌려갈 수 있었다.

## 변경

- 상어가 도착한 순간 정지·물보라·모래톱 반응을 한 번 실행한다. 구조정 이동 중에는 상어의 꼬리가 대기 동작으로 전환된다. 구조정의 기존 이동 순서·0.16초 길이와 한 번의 대기 입력은 유지한다.
- 소용돌이마다 0.18초의 진입/재등장 구간을 둔다. 실제 헤엄치는 거리에 기존 가속/감속 곡선을 적용하고, 점프 중에는 두 소용돌이 사이의 벽을 가로질러 보간하지 않는다. 효과음과 장치 반응은 구간 통과 여부로 한 번 실행하고, 짝 소용돌이로 넘어갈 때 이전 항적을 정리한다.
- 그물에 멈추면 가벼운 탄성 반응을, 부표에 멈추면 작은 크기 반응을 표시한다. 회수한 그물은 0.18초 동안 작아지며 사라진다. 논리상 회수는 즉시 적용해 바로 이동하거나 다시 설치할 수 있다.
- 숭어의 짧은 수집 잔상을 해당 칸 근처에 고정한다. 마지막 숭어는 `완료!` 표시와 조금 높은 획득음으로 구분한다. 방향이 꺾일 때 항적은 실제 이동 방향을 따른다.
- 되돌리기·재시작·수로 변경·화면 이탈 때 이전 물보라·숭어·그물 잔상을 정리한다. 이탈 시 현재 턴은 저장하되 아직 재생하지 않은 장치/정지 효과음을 새로 발생시키지 않는다.
- 동작 줄이기에서는 새 탄성/회수/소용돌이 축소·확대, 상어 늘어남, 항적, 숭어 파티클을 생략한다. 이동 결과와 숭어·장치 효과음은 유지한다.

엔진, 수로 배치, 별 기준, 힌트 정책, 스킨/보상 조건, 저장 형식은 바꾸지 않았다. 일반 이동 시간은 유지하며 일반 동작 모드의 소용돌이 통과만 0.18초 늘어난다. 효과는 기존 Canvas와 프레임 루프를 사용하며 외부 라이브러리·새 이미지 파일을 추가하지 않았다.

## 검증

- `npm test`: 80개 통과. 기존 73개에 도착 시점/한 번만 실행, 소용돌이 진입·재등장, 거친 프레임에서도 이벤트 보존, 숭어 잔상 위치, 그물 회수·재설치·되돌리기, 접촉 대상, 이탈 처리, 동작 줄이기 검사를 7개 추가했다.
- `npm run verify`: 스토리 48개 수로의 실제 해법·그물 재배치·별 기준 통과. `render.test.js`도 모든 수로의 이동 전후 저장 복원을 실제 변경된 애니메이션 함수로 검사한다.
- 브라우저의 격리된 로컬 QA 빌드에서 기존 6·40·12번 수로를 실제 키보드/포인터로 조작했다. 6번은 0.15초에 상어가 도착해 정지 반응을 시작하고 구조정 이동이 진행 중인 것을 확인했다. 40번은 0.24초에 진입 소용돌이에서 크기 0.41, 0.33초에 짝 소용돌이에서 크기 0.59로 표시됐으며 이후 정상 이동·되돌리기를 확인했다.
- 12번은 그물 회수 90ms에 남은 그물 수가 즉시 2로 복구되면서 회수 연출이 남아 있는 것을 확인했다. 되돌리면 잔상이 제거되고 그물이 복원되며, 다음 이동에서 그물 앞에 정상 정지한다.
- 수정 없는 기본 테스트 빌드에서도 320×568 화면으로 1번 수로를 6회 이동해 별 3개를 받고 다음 수로로 진행했다. 결과 조건·별·버튼이 화면 안에 표시되며 브라우저 오류 로그는 없었다.
- `build`, `build:artifact`, `build:playtest`, `cap:sync`를 실행해 단일 HTML·테스트·웹·Android 웹 자산을 동기화했다. APK/AAB 생성 및 실물 기기 검증은 포함하지 않는다.
- QA는 기존 테스트 빌드의 후반 수로 개방·기록 격리를 사용했다. 일반 동작 강제와 수동 30ms 프레임 버튼은 로컬 QA HTML에만 추가했다. 실제 기기 프레임 성능 또는 사람의 체감 평가로 집계하지 않는다. 원본 캡처는 `outputs/qa/motion5-*.png`에 보관한다.

실물 Android/iOS의 터치 감각·스피커·진동·프레임 성능은 별도 확인이 필요하다. 전체 화면의 장식 동작과 접근성/성능 종합 점검은 애니메이션 8번에 남긴다.
