# 보상 애니메이션 1–4

기존 클리어 결과는 별·진행·스킨 정보를 한 번에 표시해 획득 순서와 새 보상을 알아보기 어려웠다. 저장된 보상을 보여주는 연출을 추가했다. 이동 규칙, 별 조건, 스킨 조건, 저장 키, 힌트 정책은 유지한다.

## 구현

1. 결과 시트가 열린 뒤 240/460/680ms에 실제 획득한 별만 순서대로 등장한다. 조건 행 강조·작은 반짝임·음계 효과음을 맞춘다. 별 세 개를 얻으면 짧은 마무리 테두리를 표시한다.
2. 최고 별 갱신과 최초 완료를 구분한다. 수로 목록에 돌아올 때 갱신한 별·총 별·다음 수로·새 챕터를 한 번 강조하고, 구출 여정에서는 새 구간 표시를 한 번 재생한다.
3. 오늘의 구조작전에서는 실제로 새로 완료한 단계의 체크 표시와 다음 단계를 강조한다. 참여/완료 도장과 새 기념 배지는 기록이 증가한 경우에만 결과·구조일지에서 강조한다. 재도전으로 기존 도장을 중복 획득하지 않는다.
4. 새로 얻은 상어는 결과 시트 안에서 크게 보여준다. 내 상어의 새 카드와 선택한 카드에서 1.2초 동안 짧게 수영한다. 자동으로 장착하지 않으며 잠긴 외형은 고를 수 없다.

## 수명과 작은 화면

진행 기록은 연출보다 먼저 저장한다. 화면 변경·다음 수로 진입·엔딩 진입 시 이전 결과의 예약 효과음·진동과 스킨 미리보기를 취소한다. 숨겨진 탭에서는 보상 효과음을 재생하지 않는다. 새 보상 표시 큐는 메모리에만 유지하고 실제 대상 화면을 열 때 소비한다. 새로고침으로 이전 보상을 새 보상처럼 반복하지 않는다.

결과 제목과 하단 버튼은 고정하고 가운데 보상 영역만 스크롤한다. 다음 버튼은 별 애니메이션이 끝날 때까지 잠그지 않는다. 시스템의 동작 줄이기 설정에서는 별과 보상을 즉시 정적으로 표시하고 클리어 효과음 한 번만 제공한다. 미리보기 캔버스는 크기가 달라질 때만 다시 할당하고, 닫힌 화면의 수영은 중지한다. 새로운 라이브러리·이미지 파일은 추가하지 않는다.

## 자동 검증

- `npm test`: 73개 통과. 기존 진행 복원·구조정·장치 안내·힌트·일일/자유 수로 회귀를 포함한다.
- `tools/reward-motion.test.js`: 실제 저장/보상/결과 함수로 순차 효과음, 충족하지 않은 별, 화면 변경 취소, 숨겨진 탭, 최초 완료와 최고 기록 갱신, 도장·배지 중복, 스킨 소유·선택·미리보기 종료, 동작 줄이기를 검사한다.
- `npm run verify`: 스토리 48개 수로의 해법과 별 기준 통과.

## 브라우저 검증

- 390×844의 격리 테스트 빌드에서 첫 수로를 실제 방향키로 6회 완료하고 별 세 개·다음 버튼·2번 수로 진입을 확인했다. 브라우저의 실제 동작 줄이기 설정이 적용돼 별이 정적으로 표시됐다.
- 일반 동작은 별도 로컬 QA HTML에서 설정해 확인했다. 기존 11개 수로와 별 17개는 합성 기록이며, 12번 수로는 실제 그물 설치/회수와 방향키로 9회 완료했다. 별의 CSS 지연 240/460/680ms, 벚꽃 상어 실제 조건 달성, 자동 장착하지 않음, 13번 수로와 2장 해금 강조·새 여정 구간을 확인했다.
- 새 상어 결과는 390×844에서 112px 높이의 미리보기를 표시한다. 320×568에서는 가운데 영역이 스크롤되며 56px 높이의 두 하단 버튼이 화면 안에 유지되고 바로 다음 장으로 넘어갔다. 내 상어에서 벚꽃 상어를 직접 선택하면 사용 중 표시와 키보드 초점을 확인했다.
- 구조작전의 앞 두 수로와 과거 6일 완료 기록은 별도 합성 기록이다. 실제 세 번째 수로를 방향키 11회로 완료해 세 수로 체크·작전 완료 도장·별바다 상어를 확인했다. 구조일지를 다시 열 때 도장 강조가 반복되지 않는다. 로컬 브라우저 오류 로그는 없었다.
- 스크린샷은 로컬 `outputs/qa/reward-skin-390x844.png`, `reward-skin-320x568.png`, `reward-operation-390x844.png`에 보관했다. 합성 시험 기록과 일반 동작 강제는 배포 빌드에 포함하지 않는다.

자동 해법과 합성 저장 기록은 실제 이용자의 재미·체감 난이도 또는 실물 기기 성능 증거가 아니다. 네이티브 진동·스피커 소리·실물 Android/iOS 터치 및 프레임 성능은 별도 기기 검증이 필요하다. 웹·단일 HTML·아티팩트 빌드와 Capacitor 웹 자산 동기화를 통과했으며 앱 APK/AAB 생성 또는 설치 검증은 이번 작업 범위에 포함하지 않았다.
