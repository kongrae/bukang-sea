# 시험 코스의 정식 수로 통합

> 2026-10-07 후속: [장 재구성](CHAPTER-RESTRUCTURE.md)으로 장 구성·화면 번호·엔딩 기준(72개, 최대 별 216개)이 바뀌었다. 이전 시험 코스의 저장 인덱스(48–59)와 아래 이관 규칙은 그대로다.

2026-10-03. 별도로 보이던 ‘새 물길 시험 코스’를 일반 스테이지 흐름에 넣어 달라는 요청을 반영했다.

## 구성과 진행

- 기존 1–48번의 번호·이름·배치·그물 수·역할·별 기준은 유지한다.
- 5장 **북항 바깥길**: 49–52번(이전 p01–p04).
- 6장 **수문 시설**: 53–60번(이전 p05–p12). 53번에서 스위치·수문 안내를 제공한다.
- 48번 완료 후 49번, 52번 완료 후 53번으로 이어진다. 다음 지역 그림과 장 완료 문구도 연결했다.
- ‘수로 선택’은 여섯 장을 표시하며 별도 시험 코스 진입 버튼을 제거했다. 장별 진행·구출 여정·엔딩은 총 60개 기준이다.
- 최대 별은 180개다. 스킨의 기존 해금 기준은 유지하며, 황금 상어는 144개다. 이미 보유한 스킨을 다시 잠그지 않는다.
- 신규 이용자는 이전 수로 탈출로 다음 수로를 연다. 60개를 모두 탈출하면 엔딩을 볼 수 있다. 기존 48개 완료자는 49번부터 이어간다.

## 저장 호환

기존 `bukang-sea-v1` 키를 유지한다. `migratePilotToStory()`가 부팅 시 한 번 실행되며 `storyExpansion: 1`로 완료를 기록한다.

- 유효한 이전 별(정수 1–3)을 `pilot.best.p01–p12`에서 `best[48–59]`로 옮긴다. 동일 수로 기록이 양쪽에 있으면 높은 값 하나만 사용한다. 이전 시험 코스 별도 일반 별·스킨 조건에 합산한다.
- 이전에 완료하거나 진행 중이던 시험 수로는 정식 통합으로 다시 잠기지 않는다. 이 접근 권한은 `storyAccess`에 보관하며, 완료하지 않은 원래 스테이지의 별을 만들어 내지 않는다.
- 실제 복원 검사를 통과한 `sessions.pilot`의 위치·수문·숭어·그물·구조정·이동 수·되돌리기 기록을 숫자 스테이지 ID로 이전한다.
- 일반 스테이지와 시험 코스가 동시에 진행 중이면 일반 이어하기를 우선 유지하고 시험 코스를 `sessions.importedStory`에 보관한다. 해당 수로 선택 시 복원하며, 그때부터 기존의 단일 일반 진행 슬롯을 사용한다. 진입/완료한 보관 세션은 제거한다.
- `pilot:pXX` 힌트 사용 기록은 `story:<인덱스>`로 이전한다. 횟수와 사용 시간은 각각 큰 값을 유지한다. 다시 불러와도 이전 세션이나 힌트 사용 횟수가 초기화되지 않는다.
- 이전 시험 코스 원본은 보관한다. 다시 이전하지 않으므로 완료한 세션이 되살아나지 않는다. 설정·일일 작전·자유 수로 저장은 유지한다.

## 데이터와 검증

수로 원본은 `src/levels.js`의 `STORY_EXTENSION_LEVELS` 하나다. `LEVELS` 뒤에 추가하고 `src/pilot.js`는 이전 기록 및 검증 도구가 쓰는 별칭과 지역 팔레트를 제공한다. 내부의 이전 모드 코드는 개발 검사 호환용으로 남아 있으나 공개 메뉴에서 진입하지 않는다.

- 전체 자동 검사 **157개 통과**. `tools/story-integration.test.js`는 원래 48개 지문, 별/스킨 이전, 중복 합산 방지, 수문 세션/힌트 복원, 잘못된 저장 거부를 검사한다.
- `npm run verify`: 정식 60개 해법·이동 기준 통과. 49–60번은 기존 48개와 배치 중복, 역할별 기준과 수문 사용 필수성도 추가 검사한다.
- `tools/journey.test.js`: 48→49, 52→53 전환, 여섯 장의 진행, 60개 기준 엔딩 검사.
- 단일 HTML·아티팩트·웹/PWA 빌드 통과. 새 외부 자산이나 의존성은 추가하지 않았다. 이전에 제거한 일반 헤엄/정지 소리는 그대로 유지한다.

브라우저 검증은 실제 저장과 분리한 개발용 합성 기록을 사용한다. 기존 48개 완료 이후 49번 진입·클리어·50번 연결, 일반/시험 코스 동시 진행 이전, 53번 수문 상태와 힌트 복원·새로고침·되돌리기를 확인했다. 59개 완료 기록에서 60번을 11회 입력으로 별 3개 클리어하고 최종 엔딩으로 연결했다. 합성 진행과 자동 해법은 실제 이용자의 60개 연속 플레이나 난이도 평가 결과가 아니다. 실물 Android 검증과 앱스토어 배포는 이번 웹 반영에 포함하지 않는다.
