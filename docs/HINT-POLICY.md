# 힌트 사용 간격

## 정책

수로마다 처음 두 개의 새 힌트는 바로 제공한다. 두 번째 힌트를 제공한 시점부터 이후 새 힌트는 직전 제공 시점 기준 12초 간격으로 사용할 수 있다. 사용 횟수의 상한이나 비용은 없다. 12초는 이용자 시험으로 조정할 초기값이다.

- 버튼에 `바로 2회`, `바로 1회`, `12초 후`와 남은 초, `사용 가능`을 표시한다. 검색 중과 대기 중에는 버튼을 비활성화한다. H 단축키도 같은 제한을 적용한다.
- 이미 표시된 힌트는 `다시 보기`로 계속 볼 수 있다. 같은 다음 이동의 그물 회수·설치를 안내하는 동안 추가 횟수를 소비하지 않는다.
- 새 안내를 실제로 제공했을 때만 횟수를 기록한다. 이동/화면 전환으로 취소된 검색이나 해법이 없는 상태의 되돌리기 안내는 기록하지 않는다. 검색 중 중복 요청도 막는다.
- 스토리 수로 번호마다 누적 횟수와 최근 제공 시간을 `hintUsage['story:번호']`에 저장한다. 일일 수로는 날짜별 `hintUsage['daily:날짜']`에 저장하며 최근 120개 날짜만 유지한다. 기록은 기존 로컬 저장 키 안에 있으며 외부로 전송하지 않는다.
- 사용 기록은 이동 상태/되돌리기 기록과 분리된다. 되돌리기·처음부터·목록 복귀·새로고침으로 즉시 사용 횟수를 초기화하지 않는다. 다른 수로와 새로운 날짜에는 각각 처음 두 회가 제공된다.
- 기존 별 판정, 스킨 해금, 이동 기준, 이전 진행 기록은 유지한다. 힌트 사용에 따른 감점은 없다. 기존 저장에 힌트 기록이 없으면 처음 두 회부터 시작한다.

## 확인

- 실제 힌트 함수와 풀이기를 실행하는 6개 회귀 검사: 두 회 즉시 제공/12초 경계, 반복 안내, 저장 복원/수로 분리/기존 별·스킨 유지, 일일 날짜 분리, 취소/해법 없음, 이전 저장 호환.
- `npm test` 총 36개, `npm run verify` 48개 수로 통과.
- 격리된 관찰용 빌드의 390×844 수로 1에서 첫 두 회 제공, 같은 힌트 다시 보기, 이동 후 대기 버튼, 초기화/새로고침 후 대기 유지, H 단축키의 남은 시간 안내, 대기 만료 후 재사용을 확인했다. 수로 2는 `바로 2회`로 시작했다.
- 360×640의 힌트 버튼은 약 107×48px이며 글자 가로 넘침이 없다.
- 새 한글을 포함해 내장 폰트를 재생성했다. `build`, `build:artifact`, `build:web`, `build:playtest` 빌드를 확인했다.

이는 자동 검사와 개발자의 브라우저 확인이며 실물 기기/실제 이용자 관찰 결과가 아니다. 실제 이용자 결과는 아직 0명이며, 난이도와 힌트 의존도는 `PLAYTEST.md` 절차로 확인해야 한다.
