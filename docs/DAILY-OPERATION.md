# 오늘의 구조작전 — 콘텐츠 개선 1번

2026-09-30. 기존 하루 한 판의 오늘의 수로를 매일 세 수로로 확장한다.

## 플레이 흐름

- 메인 스토리 시작 버튼 바로 아래에서 오늘의 구조작전을 연다.
- 첫 물길(쉬움) → 굽이 너머(보통) → 마지막 탈출(도전)을 순서대로 개방한다.
- 1/3, 2/3, 3/3 진행과 수로별 최고 별, 전체 9개 별을 표시한다.
- 한 수로만 탈출해도 기존 일일 참여·연속 기록을 인정한다. 별 3개나 세 수로 완료를 요구하지 않는다.
- 결과의 다음 수로 버튼으로 바로 이어지고, 세 수로 완료 시 구출 성공 표시를 보여 준다. 다시 플레이해 별을 높일 수 있다.
- 수로별 진행과 되돌리기를 저장한다. 완료한 앞 수로를 재도전해도 미완료 뒤 수로는 유지한다.
- 힌트는 수로별 처음 2회 즉시, 이후 12초 간격이다. 재시작·새로고침으로 소비 기록을 초기화하지 않는다.
- 날짜는 기존과 같은 기기 현지 날짜다. 날짜가 지난 미완료 세션은 목록을 열 때 정리한다. 날짜 변경 전에 시작한 판을 끝내면 시작한 날짜에만 기록한다.

## 생성과 난이도

`DAILY_OPERATION_VERSION = 1`의 날짜·단계 시드로 모든 기기에서 같은 판을 생성한다. 이전 `DAILY_VERSION = 2` 생성기는 진행 호환용으로 보존한다.

| 단계 | 숭어 전체 수집 최단 이동 | 별 3개 여유 | 탈출만 할 때 최소 이동 |
|---|---|---|---|
| 쉬움 | 5–7 | +2 | 3 |
| 보통 | 8–10 | +1 | 4 |
| 도전 | 11–14 | +0 | 5 |

이동 기준은 무료 그물 재배치·움직이는 구조정을 포함한 실제 `planSearch()`로 평가한다. 숭어 수집은 탈출만 하는 경로보다 길어야 하며, 그물이 있는 판은 그물 없이는 전체 수집이 불가능해야 한다. 금요일·일요일 도전에는 그물을 사용한다. 요일에 따라 다른 장치 조합을 사용하고 단계마다 다른 수로 마스크군을 사용한다.

후보는 최대 240개, 각 풀이 검색은 최대 256회 묶음으로 제한한다. 시간 제한으로 후보를 선택하지 않아 기기 성능이 달라도 결과가 같다. 검색 중에는 브라우저에 제어를 돌려주며 준비 화면을 닫으면 취소한다. 후보가 모두 기준을 벗어나면 자동 검증된 단계별 예비 수로를 사용한다. 이동 수와 장치 조합은 설계 기준이며 실제 이용자 체감 난이도나 플레이 시간을 보장하지 않는다.

## 저장 호환

- 기존 저장 키 `bukang-sea-v1`, `best`, 스킨·설정·일일 참여 기록을 유지한다.
- `dailyOps[날짜] = { version: 1, stars: [0, 0, 0] }`로 새 작전 최고 별을 별도 저장한다. 최근 120일을 유지한다.
- 기존 `daily[날짜]`는 참여와 연속 기록용이다. 새 작전의 별은 스토리 별이나 황금 상어 조건에 합산하지 않는다.
- 현재 판은 `sessions.daily`, 단계별 판은 `sessions.dailyStages`에 저장한다. ID는 날짜·작전 버전·단계를 포함하며 맵 서명을 확인한 뒤 복원한다.
- 업데이트 전에 풀던 단일 일일 판은 `sessions.dailyLegacy`로 옮겨 ‘이전 수로 이어하기’로 제공한다. 새 작전 시작으로 덮어쓰지 않는다.
- 과거 참여는 인정하되, 풀지 않은 새 작전에 별을 지급하지 않는다. 과거 등대 상어 보유 상태도 유지한다.

## 검증

`npm test`, `npm run verify`, `npm run daily -- 365 2026-09-30`으로 회귀·스토리·일일 생성과 해법을 검사한다. 이전 단일 퍼즐은 `npm run daily -- 90 2026-09-30 --legacy`로 별도 점검할 수 있다.

자동 검사에는 단계별 저장·재접속, 앞 수로 재도전 후 뒤 수로 복원, 이전 세션 이관, 별 중복/하락 방지, 연속 기록, 힌트 분리, 날짜 변경, 준비 취소, 예비 수로 검증이 포함된다. 실제 이용자 재미·세션 길이와 실물 휴대폰 터치 검증은 별도다.

2026-09-30 확인 결과: 회귀 테스트 43개, 스토리 48개, 365일의 1,095개 일일 수로가 통과했다. 검사 기간에는 예비 수로가 사용되지 않았다. 새 작전 v1의 90일 맵·별 기준과 이전 단일 v2의 90일 맵·별 기준을 각각 해시로 고정해 호환 변경을 감지한다.

브라우저에서는 9월 30일의 세 수로를 방향키 입력으로 각각 5·10·14회에 별 3개로 완료했다. 첫 수로의 이동 후 새로고침·이어하기, 결과에서 다음 수로 진입, 3/3·별 9/9 완료, 기존 스토리 별 36개·스킨 2개 유지도 확인했다. 풀이기로 얻은 경로를 입력한 기능 검증이며 실제 이용자의 난이도·시간 측정이 아니다. 선택·완료 화면은 320×568, 일반 게임 흐름은 360×640·390×844 브라우저 뷰포트로 확인했다.

콘텐츠 개선 2번에서 누적 구조일지·추가 보상을 연결했다. 참여와 세 수로 완료를 구분하고 최근 120일 정리 이후에도 누적 도장을 유지한다. [RESCUE-JOURNAL.md](RESCUE-JOURNAL.md) 참고.
