# 메인 타이틀 가독성

## 변경 이유와 적용

작은 화면의 제목은 36px, 부제는 18px였고, 12.5px 상단 설명에 투명도 0.7이 적용돼 있었다. 좁은 줄 간격과 낮은 글자 대비를 조정했다.

- 제목: `clamp(40px, 12vw, 48px)`, 줄 높이 1.08. 360px에서는 36 → 43.2px, 390px에서는 39 → 46.8px로 커진다.
- 부제: 주아 18px → Noto Sans KR 20px/700, 줄 높이 1.3. 제목 아래 여백은 3 → 6px.
- 상단 설명: 12.5 → 13.5px, 투명도를 없애고 진한 청록 글자로 표시.
- 제목 영역은 밝은 단색 `--hero-paper: #f7f1e5`로, SOS는 진한 주황 `--title-alert: #b23517`로 표시한다. 이 조합의 계산상 대비는 약 5.47:1이며 기존 약 3.22:1보다 높다. 수로 게임판의 색은 유지한다.
- 배너 높이는 일반 화면 144 → 180px, 낮은 화면 126 → 164px로 늘린다. 텍스트 영역 위에 물결·상어 장식이 위치하며, 제목 블록에는 18px 좌우/16px 아래 여백을 준다.
- 설정 버튼에 불투명한 청록 배경과 밝은 테두리를 적용해 움직이는 장식과 구분한다. 버튼 크기와 동작은 유지한다.

## 확인

- 320×568: 제목 40px, 제목/부제 가로 넘침 없음. 이어하기 버튼 전체가 첫 화면에 보인다.
- 360×640 및 390×844: 제목/부제의 크기와 배치를 브라우저에서 확인했다. 배너가 높아진 만큼 수로 목록은 아래로 이동하며 기존 목록 스크롤을 사용한다.
- 메인 설정 열기와 기존 별 36개/수로 13의 0회 이어하기 표시를 확인했다. 제목/챕터 스토어 이미지도 갱신했다.
- `npm test` 36개, `npm run verify` 48개 수로 통과. `build`, `build:artifact`, `build:web`, `cap:sync` 확인.

이 기록은 브라우저 크기별 확인과 색상 대비 계산이며 실제 이용자의 읽기 속도나 실물 기기 시험 결과가 아니다. 이름, 저장 키, 앱 ID, 별/스킨/힌트 규칙은 유지한다.
