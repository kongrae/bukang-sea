# Google Play 등록 자료 (초안)

`[대괄호]`는 등록 전에 채울 값. "부캉이"는 상표 분쟁 중인 명칭이라 쓰지 않는다(2026-09-30 결정). 나중에 사용 허락을 받으면 앱 이름만 바꿀 수 있다(앱 ID는 불가).

## 기본 정보

| 항목 | 값 | 제한 |
|---|---|---|
| 앱 이름 | 길 잃은 상어: 바다 탈출 퍼즐 | 30자 |
| 홈 화면 이름 | 길 잃은 상어 | |
| 기본 언어 | 한국어 | |
| 앱/게임 | 게임 · 퍼즐 | |
| 태그 (최대 5개) | 퍼즐, 슬라이드 퍼즐, 캐주얼, 오프라인, 두뇌 게임 | |
| 가격 | 무료 | |
| 연락처 이메일 | [문의 이메일] | 필수, 스토어에 공개됨 |
| 개인정보처리방침 URL | [웹 배포 주소]/privacy.html | `www/privacy.html`로 함께 배포됨 |

## 간단한 설명 (80자 이내)

```
수로에 갇힌 상어를 밀어서 바다로! 숭어를 먹고 그물을 쳐서 36개 수로를 탈출하는 슬라이드 퍼즐
```

## 자세한 설명 (4000자 이내)

```
굽은 수로에 들어와 길을 잃은 상어.
화면을 밀면 상어는 벽에 닿을 때까지 쭉 헤엄칩니다. 부표와 구조정 앞에서 멈추고, 물줄기를 타면 방향이 꺾여요. 길을 잘 골라 넓은 바다로 돌려보내 주세요.

■ 이렇게 놀아요
· 위아래 왼쪽 오른쪽으로 밀어서 헤엄치기
· 숭어를 모두 먹고, 기준 이동 수 안에 나가면 별 3개
· 물 위를 톡 눌러 그물을 치면 원하는 자리에서 멈출 수 있어요
· 막히면 되돌리기, 그래도 어려우면 힌트

■ 3개의 장, 36개의 수로
1장 북항 수로 - 규칙을 하나씩 배우는 12개의 수로
2장 친수공원 운하 - 화단과 갈림길이 있는 12개의 수로
3장 방파제 너머 - 물살과 그물이 얽힌 12개의 수로
뒤로 갈수록 조금씩 어려워지고, 모든 수로는 반드시 풀 수 있어요.

■ 이런 분께 추천해요
· 짧게 한 판씩 머리를 쓰고 싶은 분
· 광고 없이 조용히 즐기는 퍼즐을 찾는 분
· 인터넷이 없는 곳에서도 할 게임이 필요한 분

■ 안심하고 즐기세요
· 광고, 결제, 회원가입 없음
· 개인정보를 수집하지 않아요. 진행 기록은 내 기기에만 저장돼요
· 인터넷 연결 없이 플레이 가능

2026년 가을 부산 북항 친수공원 수로에 들어온 상어 이야기에서 영감을 받아 만든 게임입니다. 실제 기관·캐릭터와는 관련이 없습니다.
```

## 그래픽 (docs/store/)

| 파일 | 용도 | 규격 |
|---|---|---|
| `assets/icons/icon-512.png` | 앱 아이콘 | 512×512 PNG (필수) |
| `feature-graphic.png` | 그래픽 이미지 | 1024×500 (필수) |
| `1-title.png` … `6-chapters.png` | 휴대전화 스크린샷 | 1080×1920, 2~8장 (필수) |

스크린샷 순서 추천: 1-title → 2-jets(힌트) → 3-nets(그물) → 4-clear(별 3개) → 5-chapter3 → 6-chapters.
게임 화면이 바뀌면 `npm run build:web && node tools/shots.js`로 다시 만든다.

## 콘텐츠 등급 설문 (IARC) 답변 가이드

- 카테고리: 게임
- 폭력, 성적 콘텐츠, 욕설, 약물, 도박: 모두 **아니요** (상어가 숭어를 먹는 장면은 "냠!" 효과뿐, 유혈 묘사 없음)
- 사용자 간 상호작용 / 채팅 / 위치 공유 / 디지털 상품 구매: **아니요**
- 예상 결과: 전체이용가 (국내 게임 등급분류도 이 설문으로 처리됨)

## 데이터 보안 섹션 답변 가이드

- 앱이 사용자 데이터를 수집하거나 공유하나요? → **아니요**
- (진행 상황은 기기 로컬 저장소에만 있고 전송되지 않음 → "수집"에 해당하지 않음)
- 광고 포함 여부 → **아니요** (나중에 AdMob을 넣으면 데이터 보안 답변과 개인정보처리방침을 함께 바꿔야 함)

## 타깃 연령

- 권장: **13세 이상** 또는 "전체(아동 포함)" 중 선택.
- 아동(13세 미만)을 대상에 포함하면 Google Play 가족 정책(광고 SDK 제한 등)이 적용된다. 광고를 넣을 계획이면 13세 이상으로 두는 편이 단순하다.
