## 자세한 설명 (4000자 이내)

```
상어 SOS! 굽은 수로에 갇힌 상어가 바다로 돌아갈 길을 기다리고 있어요.
화면을 밀면 상어는 벽에 닿을 때까지 쭉 헤엄칩니다. 부표 앞에서 멈추고, 물줄기를 타면 방향이 꺾여요. 한 칸씩 오가는 구조정은 때를 맞춰 지나가야 해요. 길을 잘 골라 넓은 바다로 돌려보내 주세요.

■ 이렇게 놀아요
· 위아래 왼쪽 오른쪽으로 밀어서 헤엄치기
· 숭어를 모두 먹고, 기준 이동 수 안에 나가면 별 3개
· 물 위를 톡 눌러 그물을 치면 원하는 자리에서 멈출 수 있어요
· 막히면 되돌리기, 그래도 어려우면 힌트
· 모래톱에 올라서면 멈추고, 소용돌이에 들어가면 짝 소용돌이로 나와요

■ 매일 세 수로, 오늘의 구조작전
쉬움·보통·도전 수로를 차례로 통과해 오늘의 작전을 완수해요. 한 수로만 완료해도 연속 기록이 이어지고, 중간에 나가도 이어서 즐길 수 있어요.

■ 4개의 장, 48개의 수로
1장 북항 수로 - 규칙을 하나씩 배우는 12개의 수로
2장 친수공원 운하 - 화단과 갈림길이 있는 12개의 수로
3장 방파제 너머 - 물살과 그물이 얽힌 12개의 수로
4장 외항 물길 - 멈춰 서는 모래톱, 반대편으로 빨려 나가는 소용돌이
뒤로 갈수록 조금씩 어려워지고, 모든 수로는 반드시 풀 수 있어요.
각 장의 구출 상황을 따라 바다로 가는 여정을 이어 가요. 48개 수로를 모두 탈출하면 구출 엔딩이 열립니다. 별 하나만 얻어도 여정은 이어져요.

■ 별을 모아 상어 꾸미기
별을 모으면 벚꽃·파도·단풍·눈꽃·황금 상어가 차례로 열려요. 오늘의 구조작전에 7일 연속 참여해 매일 한 수로 이상 완료하면 등대 상어도 만날 수 있어요.

■ 구조일지에 차곡차곡
참여한 날과 세 수로를 완료한 날에 도장을 남겨요. 누적 참여 3일이면 산호 상어, 세 수로 완료 7일이면 별바다 상어가 열립니다. 기념 배지도 모아 보세요. 쉬어 가도 누적 기록과 받은 보상은 남아요.

■ 이런 분께 추천해요
· 짧게 한 판씩 머리를 쓰고 싶은 분
· 광고 없이 조용히 즐기는 퍼즐을 찾는 분
· 인터넷이 없는 곳에서도 할 게임이 필요한 분

■ 안심하고 즐기세요
· 광고, 결제, 회원가입 없음
· 회원가입이나 분석 도구 없음. 진행 기록은 내 기기에만 저장돼요
· 인터넷 연결 없이 플레이 가능

2026년 가을 부산 북항 친수공원 수로에 들어온 상어 이야기에서 영감을 받아 만든 게임입니다. 실제 기관·캐릭터와는 관련이 없습니다.
```

## 데이터 보안 섹션 답변 가이드

- 앱이 사용자 데이터를 수집하거나 공유하나요? → **예** (2026-10-02부터. `Launchpad.java`가 LaunchPad 품앗이 링크로 설치된 경우에만 Play 설치 참조 문자열을 apptesters.cc로 한 번 보낸다. 진행 상황은 기기 로컬 저장소에만 있고 전송되지 않음)
  - 데이터 유형: **기기 또는 기타 ID**(설치 참조 문자열의 LaunchPad 앱 번호·품앗이 번호) → 수집됨, 제3자(LaunchPad)와 공유됨, 임시 처리 아님, **선택 사항**(테스터 링크로 설치한 경우만), 목적 **앱 기능**(테스트 참여 확인)
  - 전송 중 암호화 → **예**(HTTPS) / 삭제 요청 방법 제공 → **예**(개인정보처리방침의 문의 이메일)
  - 다른 데이터 유형(개인 정보, 위치, 앱 활동 등)은 모두 수집하지 않음
- 광고 포함 여부 → **아니요** (나중에 AdMob을 넣으면 데이터 보안 답변과 개인정보처리방침을 함께 바꿔야 함)

## 타깃 연령

- 권장: **13세 이상** 또는 "전체(아동 포함)" 중 선택.
- 아동(13세 미만)을 대상에 포함하면 Google Play 가족 정책(광고 SDK 제한 등)이 적용된다. 광고를 넣을 계획이면 13세 이상으로 두는 편이 단순하다.
